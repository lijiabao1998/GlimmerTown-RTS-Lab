## 怎麼玩

遊戲裡右上角的「？」也有一份說明。

沙盒（R128）：點「沙盒模式」進入同種子的 32×32 村莊，初始空軍力、暫停。選我方／敵方與坦克／榴彈砲後點空地放置，切「指揮」可沿用我方選取、移動與砲擊；敵方只沿用自動還擊，沒有電腦指揮或補給。最多建立 32 輛（含殘骸），滿額請「重置」；重置回空軍力暫停並還原村莊。「開始／暫停」控制戰鬥，「一般模式」回到原布陣。沙盒全圖可見，暫停放兵不推進移動、裝填、彈道或煙幕；不以全滅結束。

1. **布陣**：開局停在第 0 步。點藍色的我方半場蓋房子當掩體——農舍 1、磚房 2、穀倉 3，建材共 8；「轉向」轉磚房、「復原」拿掉最後一棟、點蓋好的房子也能拿掉。不能蓋的地方提示列會寫原因。
2. **開戰**：按「開戰」。敵人也會在他那半邊蓋房子。
3. **選取**：點我方單位（藍圈）；「全選」選全部。受傷或被選中的單位頭上有血條，提示列顯示平均血量與各自在做什麼。
4. **下指令**：點地面＝移動；點敵人（紅圈）＝攻擊；點房子＝轟它；「砲擊」模式下點地面＝榴彈砲對那一格開火。選中的單位地上會畫路線（綠）、攻擊線（紅）、砲擊準星（橘）。
5. **結局**：一方全滅時慢動作、鏡頭移到最後一擊，接著出戰報（擊毀、損失、轟塌、開火、你蓋的房子還站著幾棟）；「再來一局」回到布陣。

- 手勢：單指拖曳平移（放手會滑一段）；雙指捏合縮放（對準手指）；雙擊我方單位＝鏡頭跟過去。桌機：右鍵下指令、滾輪縮放（對準游標）、空白鍵暫停、Esc 取消選取。
- 快捷操作（R109）：桌機 Shift＋左鍵拖曳可把框內我方加入選取；普通拖曳仍平移。手機長按地圖半秒，放手後再點「高爆砲擊」或「煙幕」。高爆只命令榴彈砲／迫擊砲，煙幕只命令榴彈砲；混選的其他單位保持原指令。這次選單不改工具列模式；取消或點選單外不會發命令。
- 坦克被房子擋住時，砲彈打在房子上。房子三段損壞：完好 → 沒屋頂的空殼（起火、冒煙）→ 瓦礫（可以走、不擋射線）。
- 射程提示（R113）：單選一個我方武器，金圈表示名目最大射程，紅圈是最小射程死角；目前有效、停定的對地砲擊才有橘色「散布上界」。這是落點範圍的保守包圍圈，不是命中機率或爆炸半徑，也不保證穿牆。資料隨已套用指令、觀測與校準更新；暫停排入但尚未執行的指令不當成新解。多選聯合射界、自動選敵／追擊目標的散布預測尚未提供。
- 榴彈砲射程遠、有最小射程、移動中不能打；要有友軍看得到目標才打得準（盲射散布加倍），同一個目標連打、看得到落點會越打越準。觀測員視野最遠、可以進駐房子。
- 車輛會互相擠開，不會疊成一台。
- 連線合作（R083）：兩個人一起指揮我方打電腦。一台電腦先建置遊戲頁、開轉發伺服器（下面「開發」那一段的兩行），同一個區域網路裡的人用瀏覽器開它印出來的網址。開始選單按「連線合作」：一個人按「開房」（房號隨機 4 碼），照平常選地圖、布陣；另一個人輸入同一個房號按「加入」；開房的人按「開戰」，兩邊就進入同一局。也可以把網址加上 `?room=<房號>&net=join` 傳給對方直接加入。右上那一行寫房號、幾個人、來回延遲；等對方超過半秒會寫「等另一位玩家…」。任何一方打開選單（暫停），另一方也會停下來等。對方離線之後你自己繼續打。限制：要在對方加入之後才開戰（開打之後才進來的人進不了這一局）；一局打完（或重開、回主選單、看重播）連線就結束，要再打一局就再開房、再加入；斷線不能重連（斷了就各自繼續打）；兩個人都指揮我方（對打見下一條）；放上網要一台大家都連得到的主機（還沒有）。
- 連線對戰（R085）：兩個人對打，沒有電腦。開始選單按「連線對戰」（跟連線合作同一頁）：開房的人指揮右下，照平常選地圖、布陣、開戰；加入的人指揮左上（左上的布陣先由電腦代排），開戰時鏡頭在左上。各自只選得到、只看得到自己那一方（戰爭迷霧照自己那一方），生產列、補給、指揮部、勝負與戰報都照自己那一方；腳下的圈藍色是自己的、紅色是對方的（軍服顏色照陣營：右下橄欖綠、左上野戰灰）。分享的連結：房主開 `?room=<房號>&net=host&vs=1`，對方開 `?room=<房號>&net=join`。對戰中一方停住（暫停、切到別的分頁）超過一分鐘，另一方就當他離線、自己繼續打（合作照舊一直等）。打完的對戰存在重播裡，照自己那一方的角度看。限制：左上的布陣由電腦代排；對方離線之後他那一方沒有人指揮（不交給電腦）；對戰的局不自動存。
- 音效（R117）：預設靜音，右上音效鍵可開／關可見坦克與火砲的程序砲聲、彈著爆炸及房屋倒塌。暫停、開說明／戰報、切到背景或重開會清掉舊聲音；不播放隱藏敵軍或批次重播的歷史聲。瀏覽器不支援時仍可正常遊玩，音效不影響聲測情報、模擬或存檔。
- 戰壕（R118）：布陣列選「戰壕」，可放直段（2格／1點）、折線（3格／2點）、交通壕（4格／1點）、加固段（2格／2點）。與房屋共用8點建材，「轉向」每次90度；點壕溝任一格拿掉整段並退還，復原也可取消。相鄰段自動接線，任一方單位可穿行，速度／視線不變；命中格承傷依序75%／75%／90%／50%，與其他掩護取最強而不疊乘。只在開戰前布置，不能挖道路、泥灘、建物或單位所在格；HQ會避開已放的戰壕。壕溝的掩護是遊戲抽象，沒有本卡新增的戰時挖掘、修理或破壞。
- 鐵絲網（R121）：布陣選「鐵絲網」，2×1格可旋轉，花1點共用建材、耐久60。觀測員、步兵、徒步迫擊砲與機槍組（R081 起；R080 的局裡機槍組穿得過去）繞行，車輛可通過；不擋視線或提供掩護。榴彈砲擊可破壞，殘骸可通行。不能封死徒步通路。
- 圍牆（R120）：布陣選「圍牆」，矮磚牆／石牆／混凝土牆皆佔2×1格，可旋轉連接，花1／2／3點建材、耐久130／220／360，與房屋及戰壕共用8點。相鄰牆可接，其他建物仍隔一格；不能封死原本可達的空地。牆是可破壞建築，整段歸零才打開兩格缺口，瓦礫仍減速；矮牆也擋視線與直射，不能射越。觀測員與步兵沿用普通建築駐守及50%掩護，混凝土牆沒有碉堡的額外抗直射。沒有戰時建造、門或修理。
- 樹籬與小樹林（R116）：新局的鄉間植被可穿行，中間植被遮住視線，林緣可探頭；所在植被格使投射物傷害剩50%，與彈坑／房屋／碉堡取較強掩護、不疊乘。建房與指揮部會永久清除佔地植被，房屋倒塌不長回；舊指令紀錄不新增植被。

## 試玩看什麼（給業主的十分鐘清單）

1. 手機打開，先在路口南邊蓋兩棟磚房擋住敵方觀測員的視線，再按「開戰」。
2. 全選、點敵方坦克：看三輛坦克分開走（不疊）、地上的路線與攻擊線、草地上壓出來的車轍。
3. 把鏡頭拉近一棟正在被打的房子：屋頂炸飛、屋裡起火、倒塌時整棟沉進地面揚起一大團塵。
4. 擊毀一輛坦克：砲塔飛起來落在車旁，殘骸一直燒。
5. 打完看戰報，按「再來一局」。
6. 不下任何指令看 2–3 分鐘：電腦（預設普通）會帶坦克沿著房子掩護推進、集火、用榴彈砲配合觀測員把你打光；再試 `?ai=3`（困難）與 `?ai=1`（簡單）。
7. 開戰後用下方的生產列花補給出兵（坦克 40、榴彈砲 50、觀測員 15，補給每秒 +1）：守住右下角的指揮部（藍旗），打掉對方左上角的指揮部（灰旗）才算贏；電腦也會出兵。
8. 步兵班（一班 6 人）：選起來點一棟房子就進駐，在裡面受傷減半、可以往外打；步槍打不動坦克。拉近看人一個一個倒下。
9. 新砲：生產列的「反戰車砲」（架好才打、專打坦克，打步兵沒什麼用）和「迫擊砲」（越過房子打後面的人，兩個砲手）。試試看用反戰車砲埋伏在街角等坦克。
10. 新坦克：「輕坦克」快、看得遠，拿來找敵人；「重坦克」慢、很硬，頂在最前面；原本的「坦克」是中坦克。
11. 碉堡：布陣時多一個「碉堡」（3 點）。步兵、觀測員躲進去只吃四分之一傷害；坦克和步槍很難打壞它，要用榴彈砲或迫擊砲砸。
12. 地圖是 **1940 年的 Rye**（東薩塞克斯）：上方是敵軍登陸的 Camber 沙灘與 Rye Harbour，中間山丘上是舊城（High Street、石板路的 Mermaid Street、St Mary's 教堂、Ypres Tower、Landgate 城門），兩邊是河與泥灘（走得過但很慢），橋是要道。
13. 拉近看街景：房子有三種外牆——米白灰泥配深色木框（木構）、二樓掛紅陶瓦（掛瓦）、白色橫木板（護牆板）。
14. 鎮上的街：貼著房子有窄窄的人行道，路緣漆成黑白相間——1939–40 年燈火管制時英國真的這樣漆，讓摸黑的人看得到路邊。
15. 更多坦克（R044）：生產列多「裝甲車」（快、看得遠、打坦克很弱，拿來偵察）、「驅逐戰車」（長砲管、打坦克很痛，要停下來才能開火；車頂開放，被步兵貼近會吃虧）、「突擊砲」（低矮、正面硬，拆房子最快）。電腦（普通以上）也會出。
16. 大地圖（R043）：布陣時左上的「地圖」鍵換成 64×64 的英格蘭東南鄉間（或網址加 `?map=64`）。一條河從東北斜到西南、穿過中間的市鎮，十字大街就是橋，兩岸各一個小村；雙方各一個裝甲連起手（中坦克 6、輕坦克 2、重坦克 2、榴彈砲 3、觀測員 2），同時活著的兵最多 40。拉遠看整張圖，試試從村路的橋包抄。
17. 喪屍防守（R045）：布陣時按「喪屍」，或網址加 `?mode=zombies`；也可搭配 `?map=64`。喪屍從邊緣一波波湧來，只會近身攻擊。用掩體、火力與生產守住我方指揮部，失守後看波數、擊倒數與本機最佳紀錄。再按一次「喪屍」回一般對戰。
18. 河鎮（R130）：按「96×96 河鎮」或加 `?map=96`，進入有密集街廓、多個村莊、田野與河道的新圖；可搭配 `?mode=zombies`。原本 32／64 圖與操作保留，人口仍為每方 40；遠景與特寫使用不同幾何細節，碰撞及建築破壞資料完整保留。本輪為 Draft，尚未發布。
19. 遭遇戰設定（R046）：開始選單按「遭遇戰設定」，選兵力（精簡／標準／加倍）、補給速度（慢／標準／快）、種子（打字或按「隨機」）；地圖多一張隨種子變的「村莊 32×32」。每改一項，後面的戰場當場換。也可以直接寫在網址：`?force=1|3`、`?supply=1|3`、`?map=village`、`?seed=`。
20. 重播（R047）：打完一局（分出勝負）會自動存在本機，最多留十局。開始選單按「重播」，點一局就從頭重看（⏸ 與 1×／2×／4× 照舊可用，點地圖不會下指令）；播到底會說跟原局相不相同。每一局可以「匯出」成 `.json` 檔，也可以「匯入」別人給的檔。
21. 穿甲與裝甲厚度（R051，擬真規則，預設關）：開始選單 →「遭遇戰設定」→「擬真規則」打開。之後穿甲彈要穿得透那一面的裝甲才有傷害，穿不透就彈開（冷白色的火花往上彈走）；榴彈砲的高爆彈不受影響。選「鄉間 64×64」最容易看到：雙方各有兩輛重坦克，中坦克的砲從哪一面都打不穿它，要靠砲兵。戰報會多一列「跳彈」。各車的厚度與各砲的穿深見 `docs/tasks/R051-穿甲與裝甲厚度.md`。
22. 士氣與壓制（R052，擬真規則，預設關）：同一頁的第二顆開關。打開之後，步兵與砲組（沒有裝甲的單位）被打到會累積「壓制」：頭上多一到三個小方塊——一個黃的是受壓（開火與移動都剩一半）、兩個橘的是釘住（趴下不能動，開火剩四分之一）、三個紅的是潰退（不開火；在空地上的步兵會自己往後退幾格，退的時候不聽指令；實戰裡不常見，多半還沒到這一步就陣亡了）。搬到一半被釘住的砲不能開火（砲沒架好）。選中砲的時候，下面那行字會寫有幾個被壓制、裝填還要多久。砲彈不必打中，落在附近就壓得住人；停火幾秒就恢復。躲在戰壕、房子、碉堡裡比較不容易被壓住；靠近自己的指揮部也比較穩。打法：先用迫擊砲或步兵把對方壓住，趁他們抬不起頭的時候衝上去。坦克不受影響。新開的局裡電腦對手會利用這條規則（見下一項）；舊重播裡的電腦照舊不會。
23. 電腦對手第二版（R057）：新開的局，敵方電腦會先在自己指揮部前面集結，湊齊一波（簡單 3、普通 4、困難 5 台）或等滿 45 秒才出發，不再出一台送一台；前面的車打剩沒幾台會退回去等下一波（一開始退就退到底）；前面還有車在打的時候，新出的直接去會合。它的砲兵在同一個地方打滿三發會挪到隔壁（你用聲測找它會比較難），聽出你的砲在哪裡也會打回來（它正在轟你的指揮部、或那一帶有它自己人的時候不會）。開著「穿甲與裝甲厚度」時，它不再追著打不穿的那一面打：改打打得穿的目標（射程外看得到的也會追過去）、落單的目標會派離得最近的一台繞到側面、都不行就退出對方的射程讓砲兵來（它只是不再下令去打；退不掉、對方又是射程裡唯一的目標時，砲手照樣會開火）。開著「士氣與壓制」時，它的步兵受壓會躲進最近的房子，迫擊砲先壓還沒被釘住的班，你的班被釘住時它的步兵會衝過來。舊的重播與存檔照舊用第一版播。
24. 繼續上一局（R074）：開戰之後遊戲每幾秒自動存一次（切到背景、關掉分頁時也存）。下次開頁，開始選單的「開始」上面會多一顆「繼續上一局」（下面一行小字寫哪張圖、打到幾分幾秒、種子），按下去回到上次那一步、先停在暫停（布陣時從「選單」鍵叫出來的選單也有這顆鍵）；暫停時下好還沒執行的指令、戰報的數字、鏡頭位置都跟著回來。暫停選單的「回主選單」會先存一次。打完（分出勝負）存檔就清掉，那一局在「重播」裡。存檔壞掉（檢查碼對不上）就當作沒有。只有一格，開新的一局打下去就會蓋掉；沙盒、看重播時不存。
25. 指揮部倒了就結束（R077）：新開的局，一方的指揮部被打成瓦礫，這一局當下就結束、出戰報。以前要等天上所有砲彈都落地才宣布，砲多的大地圖上常常拖好幾分鐘。只有一種情況還會等：有砲彈正飛向剩下的那棟指揮部（兩棟一起倒算平手）。舊重播照舊。
26. 看得懂（R075）：開著擬真規則時，選中自己的單位，下面那行字會多寫——同一種車的裝甲厚度（正／側／後）、砲的穿深（近／遠）、步兵與砲組現在的士氣（穩定、受壓、釘住、潰退各幾個）。被釘住或垮掉的步兵班會趴在地上。新開的局，士氣規則是第二版：看到旁邊的人倒下更容易慌、打殘的班更容易垮、垮了的人只有碉堡與戰壕留得住（在房子裡的會棄屋往後跑五格）——潰退從每局不到一次變成兩三次，把人壓垮就能把房子清出來。設定頁「擬真規則」下面有兩條規則的說明。舊重播照第一版播。
27. 擬真／經典（R076）：遭遇戰設定頁的兩顆開關（穿甲、士氣）收成一個選擇——「擬真」兩條都開、「經典」都不開；開始選單那行摘要也寫擬真或經典。選過的會記住。用舊網址（例如 `?ap=1`）只開一條時，兩個都不亮，說明最前面會寫目前只開了哪一條。新開的局預設還是經典：把擬真當預設之前量了六件事。R076 量的時候「電腦的難度分不分得出高下」沒過（電腦對電腦時簡單贏困難）；R078 把電腦修好之後重量，難度分得出來了，但六件事只過四件——沒過的兩件量的是擬真跟經典差多少（普通對簡單低 16 點、萊伊上普通對普通偏心差 20 點），所以預設照舊是經典，等業主一句話或之後的卡。
28. 建築抗鋸齒預設關（R079）：業主看過開與關的對照圖，選了關——開著的時候屋頂斜邊比較平順，但木構架、窗格這類細的深色線會變淡。想看開著的樣子，在網址加 `?msaa=4`（2、4、8 都可以；手機或沒有顯示卡的機器可能開不了）。
29. 難度校正（R078）：新開的局，電腦是第三版——三個難度現在分得出高下。以前普通與困難的電腦把補給花在「每種支援兵種各保持一個」上，死一個補一個，幾乎輪不到造坦克，結果電腦互打時簡單反而贏困難。現在普通以上是「主力優先」：每兩台坦克才配一個支援單位（步兵、砲、裝甲車），主力滿四台之後才加突擊砲、重坦克（困難）或輕坦克（普通）。簡單照舊只造中坦克、一班步兵、一門榴彈砲。戰術（分波次、懂穿甲、懂壓制）沒有變。舊重播與舊存檔照舊。
30. 機槍組（R080）：新開的局，雙方一開始各多一組機槍組（三個人、一挺架在三腳架上的重機槍），生產列也多一個「機槍組」按鈕（30 補給）。它要停下來才能打、射程 12 格（步槍的兩倍），打不死多少人，但**專門壓制**：擬真規則的局裡，一次點射加的壓制比步槍一次齊射多一點、點射的間隔只有步槍的一半，落點附近 1.5 格內的其他敵人也被壓（各加一半）——空地上的步兵班被它盯上，一秒多就趴下、兩秒就往後跑。它打不動坦克（待命時不會自己去打封閉車身的車），自己沒有裝甲，怕砲彈。電腦會帶著它跟主力走、先壓還沒趴下的；看到你的機槍組，它的迫擊砲與榴彈砲會先打它，手上沒有在打車的坦克也會改打它。經典規則的局裡沒有壓制，它只是一個射程長的輕武器。它沒有自己的聲音（步槍也沒有）；喪屍防守也會送一組，但它打喪屍幾乎沒有傷害、也壓不住喪屍。數字是暫定的。
31. 地勢與視線（R055，第一段）：開始選單的「地圖」那一列多一張「丘陵」（32×32；網址也可以寫 `?map=hills`）——第一張有高低的地圖。一道稜線橫在雙方之間，中央一個隘口，兩邊山腳各一個小丘。在這張圖上：**稜線會擋視線**，躲在稜線背後（反斜面）對方看不到，直射的武器（坦克砲、反戰車砲、步槍、機槍）也打不到；下了攻擊指令的單位會自己往前開、翻上稜線再打。**站得高看得遠**（每高一階多看一格，最多兩格）。榴彈砲與迫擊砲照樣能越過稜線打，但沒人看得到的目標打不準。站在高台中間看不到坡腳，要站到邊上。地面用明暗與一道道深色的線畫出高低（地面本身還是平的，車不會真的爬高）；選中站在高處的單位，提示列會寫「高度 N」。電腦還不懂地形。其他地圖沒有高低，一切照舊。
32. 機槍組第二版（R081）：新開的局裡，機槍組算徒步單位——完整的鐵絲網擋得住它，要繞；它的點射打在房子上只壓屋裡的敵人，不會把自己進駐的人壓垮；電腦的機槍組只挑打得到的目標（中間有房子或稜線擋著，就先往旁邊三格內、走得到的地方換個位置；經典規則下不往目標進駐的房子打，打了也沒效果）。電腦互打時，困難、普通的機槍組幾乎不再對著牆打（0%、1%；第一版六、七成）；簡單每 4.5 秒才想一次，目標在中間躲到房子後面時，還有一成多的點射打進房子。疊在一起的單位（例如開局的步兵班和機槍組），隔一下再點同一個位置就換選疊著的下一個；疊著的旁邊的敵人照樣點得到；很快地連點兩下照舊是鏡頭跟過去（選的是第一下選到的那一個）。戰報的「開局」把第 0 步補給送的步兵班、機槍組算進去，擊毀與損失改成數雙方真的陣亡了幾個（中途造的新單位不再讓它少算、變負的）。步槍、直射砲打在房子上照舊不分敵我。
33. 連線合作（R083）：兩個瀏覽器（同一台電腦開兩個視窗也行）照上面「怎麼玩」的連線合作那一條開房、加入；房主開戰之後，在一邊下指令，另一邊看得到同一隊車照著走；右上的延遲與「等另一位玩家…」。
34. 左右對稱（R084）：新開的局裡，左上那一方（電腦）跟右下那一方用同一套規矩——多選幾台下移動指令時，雙方的隊員都排到目標靠自己家那一邊（原本左上那一方的排到前面、右下的排到後面）；指揮部的位置、出生格、集結點、尋路平手時也照鏡像。電腦對電腦在對稱的丘陵上不再一面倒（經典原本右下 30 局全輸）。看不出來的話是正常的：它讓雙方公平，不改玩法。
35. 連線對戰（R085）：兩個瀏覽器照上面「怎麼玩」的連線對戰那一條開房、加入；加入的那一邊鏡頭在左上、全選只選到左上那一方的車、生產列下的是左上那一方的；右下那一方的車在霧裡看不到；雙方各下指令，兩邊看到的是同一局。
36. 房屋細化（R086）：拉近看一個鎮——每棟磚色、屋頂色、門色不一樣；屋頂有雙坡、四坡、半四坡；煙囪頂上有煙囪管；有的門上有門罩；商店有展示窗和條紋遮陽棚；穀倉有大車門（有的開著）和山牆上的乾草口；教堂正面有拱門和圓窗、側面有尖拱窗和扶壁、塔上有鐘樓開口。網址加 `?noR086=1` 對照原本的樣子。
37. 更多房屋（R087）：新開的局每張地圖多幾棟房子，還有三種這一帶才有的——**啤酒花烘房**（磚砌的八角烘爐、圓錐頂、白色風帽）、**塔式風車**（白色木板塔身、四片風帆）、**河岸倉庫**（一樓磚、上面塗焦油的黑色木板、頂樓吊貨的小屋）。萊伊：河西岸草地上一座風車，The Strand 河邊那三棟穀倉換成三層的倉庫；丘陵：一對風車、一對烘房；村莊多 6 棟、64 圖多 12 棟、96 圖多 20 棟以上（每一棟在對面都有一棟一樣的）。新房型照材質算耐久（烘房是磚、風車與倉庫是木），一樣能駐守、擋視線、被打塌；不能拿來布陣。舊的紀錄與存檔一模一樣
38. 建築破壞的過程（R088）：房子挨打時一路看得出來——先是牆上打出洞、屋頂掉一塊瓦、窗戶破了，再來屋頂一頭塌下去；變空殼的那一刻屋頂塌進屋裡，再打下去空殼塌一半，最後分兩段往外倒成瓦礫。只改畫面，模擬一行不動（重播、存檔、連線都不受影響）
39. 更大規模的步兵（R089）：一個步兵班畫成十個人——走路時排成兩路縱隊、停下來排成兩列（正在打就轉向敵人）、被壓住時趴成散兵線、在屋頂上擠一點；少一個人就多一個躺著的人，班長和布倫機槍組最後倒。看不到的不畫，人一多整群小兵自動換成省一點的畫法（先拿掉小兵的影子、再換簡化的模型），手機上的大戰照樣順。只改畫面；排、人口上限是之後的 R095
40. 步兵排（R095）：新開的局，生產列多一顆「步兵排」——66 補給一次出三個步兵班（比三個單班便宜），三班集結在相鄰的三格；選其中一班按「全排」（桌機按 P）就選到整排。同時活著的兵上限提高（萊伊與村莊 24、鄉間大圖 48、河鎮 64），多選移動的隊形排到 25 格才重疊；困難的電腦主力夠了會出排。舊紀錄、存檔照樣重播
41. 更大的戰場（R090）：設定頁多一張「海斯」（128×128，原本最大的河鎮是 96×96）——1940 年 9 月英格蘭東南海岸的海斯與皇家軍事運河：左上的海灘有三座圓形砲塔，運河沿著斜線橫過畫面，只有五座橋過得去（泥地也走得過，只是慢），四座橋的內陸那頭有碉堡；鎮上有教堂，丘陵上有兩座城堡與林普恩機場。圖大了，尋路在這張圖上多估一點、走不到的終點就近換一格，大軍下指令不會卡；小地圖一次畫好。舊地圖、舊紀錄完全不變
42. 步兵支援兵器（R091 第一段）：生產列的分組選單多一組「步兵支援」——**狙擊手**（兩個人，射程 11 格比多數步兵、砲組、坦克看得到的遠；一發打倒一個人，先挑觀測員、機槍組、砲組；不打封閉車身的車；可以進房子；剋星是觀測員找到它、再用迫擊砲或榴彈砲轟）與**反戰車小組**（兩個人、3 格內打空心裝藥的穿甲彈；大車要打側面、後面；只打車；不能進房子，躲在樹籬後面用「開火」鍵先停火、等車開到旁邊再放）。兩種都要停下來才能打、鐵絲網擋得住；喪屍防守不開放。反戰車小組照 PIAT、巴祖卡那一級做，1940 年的海斯其實還沒有。電腦不造、不指揮這兩種兵（量過：在大地圖上坦克 9 格外就把反戰車小組打掉，一發都沒開），但第三版的迫擊砲、榴彈砲看得到對方的狙擊手就先打它。

## 開發

```bash
npm ci
npm run dev        # 開發伺服器（埠 8401）
npm run check      # 型別 → Node 守衛 → 建置單檔 → 無頭 Chrome 煙霧測試
```

連線合作（R083）的轉發伺服器：零依賴，一個檔案。

```bash
npm run build                 # 先建遊戲頁（伺服器順便伺服 dist/）
node server/relay.mjs         # 預設埠 8788；--port、--host 可以改；印出區域網路的網址
```

伺服器只轉訊息（房間最多 2 人；開房拿 0 號、加入拿 1 號；不存世界、不懂規則）；兩邊各自跑同一個決定性的模擬，每一步只送自己下的指令（鎖步，延遲 4 步＝0.2 秒），每 100 步互相比一次世界雜湊。同步的程式在 `src/net/`，守衛 `tests/net-lockstep.mjs`（Node）與 `tests/net-browser.mjs`（兩個 Chrome）。對戰（R085）時鎖步只收每個人自己那一方的指令；畫面與介面的「我方」是 `src/side.ts` 的活的綁定（模擬不碰它），守衛 `tests/versus.mjs`（Node）與 `tests/versus-browser.mjs`（兩個 Chrome）。

煙霧測試與 R109 真實輸入守衛需要 Chrome／Chromium（`CHROME_PATH` 可指定）。R109 守衛自行建置暫存 bundle，CI 必須實跑；本機若受 socket 權限限制會以 77 明列未跑，不當作通過。樣張存在 `shots/`（不進倉庫，CI 當附件）。R117音效守衛檢查真實WebAudio狀態、音訊圖與OfflineAudioContext輸出；既有無頭Chrome使用mute-audio，不代表已驗證喇叭音質或Android實聽。

R128 沙盒重播使用明確的 `createSandboxWorld(seed)` 初始世界；`LoggedCommand.tick` 對沙盒是指令步序（`commandTick`／`sandbox.frame`），`World.tick` 仍是戰鬥時間。`runLog` 的終點在沙盒以指令步序計，普通世界沿用戰鬥 tick。瀏覽器掛勾 `__rts.playLog(seed, log, frames, true)` 的第四參數明確選沙盒，舊的三參數呼叫不變。重置保存步序，JSON 紀錄可重播整串放置／暫停／重置；這一版沒有新增玩家存檔／匯入介面。

### 彈坑輕掩體（R106）

站在已有彈坑格的單位只承受 75% 投射物傷害，但仍受到原本彈坑減速。三種深度的減傷相同；移出彈坑就失去掩護。普通房屋與碉堡的更強掩護不再疊加彈坑效果，建築倒塌傷害不減。高爆彈先命中再挖坑，製造第一個坑的那發仍吃完整傷害。沒有新增畫面效果或開關，指令與存檔格式不變。

### 榴彈砲煙幕（R107）

選榴彈砲後，把彈種從高爆切到煙幕，再沿用砲擊方式點目標。煙幕任務最多打四發，點建築也不會一直射；混選時只有榴彈砲接煙幕命令。切回高爆後再點目標，或下新的移動、攻擊、停止命令即可換任務。

煙幕不傷人、不拆房、不挖坑，只遮住雙方視線。每團半徑 2 格，維持 20 秒，隨該局固定風向緩慢漂移；最多同時 8 團，超過時移除最舊一團。繞到另一側的友軍仍能觀測，已知座標也仍可盲射，煙幕擋不住炮彈。煙團與風都記在世界裡，讀取與重播不會憑空消失。

### 反砲兵粗略情報（R115）

敵方榴彈砲或迫擊砲真正開火後，小地圖會出現橙色虛線的「疑似敵砲區」。這是砲聲線索，不是敵軍位置標記：不會打開迷霧、顯示敵砲模型或把點擊變成精確鎖定。可以沿用小地圖點擊移鏡，再選擇盲射壓制，或讓觀測員前去確認。

同一個2×2格子區連續開火，估計範圍分三階縮小；橢圓半軸為8×6、4×3、2×1.5格，第三階仍保留位置不確定性。每個8×8粗區只記最近聲源，不辨認是哪一門砲；不同砲在區內交替開火可能讓估計重新變寬。同時開火有固定子區優先順序，沒有因單位ID洩漏位置。

線索自最後一發起維持30秒（暫停時不倒數），每方最多8區。沒再開火時，敵砲悄悄移動或被擊毀都不會即時改變舊圈；換區後重新開火才給新線索。煙幕發射也有砲聲。全32格戰場接收聲測與上述數字是二戰聲測概念的玩法抽象，不代表真實器材精度。
