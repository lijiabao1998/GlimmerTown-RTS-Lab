## 怎麼玩

遊戲裡右上角的「？」也有一份說明。

沙盒（R128）：點「沙盒模式」進入同種子的 32×32 村莊，初始空軍力、暫停。選我方／敵方與坦克／榴彈砲後點空地放置，切「指揮」可沿用我方選取、移動與砲擊；敵方只沿用自動還擊，沒有電腦指揮或補給。最多建立 32 輛（含殘骸），滿額請「重置」；重置回空軍力暫停並還原村莊。「開始／暫停」控制戰鬥，「一般模式」回到原布陣。沙盒全圖可見，暫停放兵不推進移動、裝填、彈道或煙幕；不以全滅結束。

1. **布陣**：開局停在第 0 步。點藍色的我方半場蓋房子當掩體——農舍 1、磚房 2、穀倉 3，建材共 8；「轉向」轉磚房、「復原」拿掉最後一棟、點蓋好的房子也能拿掉。不能蓋的地方提示列會寫原因。
2. **開戰**：按「開戰」。敵人也會在他那半邊蓋房子。
3. **選取**：點我方單位（藍圈）；「全選」選全部。受傷或被選中的單位頭上有血條，提示列顯示平均血量與各自在做什麼。
4. **下指令**：點地面＝移動；點敵人（紅圈）＝攻擊；點房子＝轟它；「砲擊」模式下點地面＝榴彈砲對那一格開火。選中的單位地上會畫路線（綠）、攻擊線（紅）、砲擊準星（橘）。
5. **結局**：一方全滅時慢動作、鏡頭移到最後一擊，接著出戰報（擊毀、損失、轟塌、開火、你蓋的房子還站著幾棟）；「再來一局」回到布陣。

- 手勢：單指拖曳平移（放手會滑一段）；雙指捏合縮放（對準手指）；雙擊我方單位＝鏡頭跟過去。桌機：右鍵下指令、滾輪縮放（對準游標）、空白鍵暫停、Esc 取消選取。
- 快捷操作（R109）：桌機 Shift＋左鍵拖曳可把框內我方加入選取；普通拖曳仍平移。手機長按地圖半秒，放手後再點「高爆砲擊」或「煙幕」。高爆只命令榴彈砲／迫擊砲，煙幕只命令榴彈砲；混選的其他單位保持原指令。這次選單不改工具列模式；取消或點選單外不會發命令。
- 坦克被房子擋住時，砲彈打在房子上。房子三段損壞：完好 → 沒屋頂的空殼（起火、冒煙）→ 瓦礫（可以走、不擋射線）。
- 射程提示（R113）：單選一個我方武器，金圈表示名目最大射程，紅圈是最小射程死角；目前有效、停定的對地砲擊才有橘色「散布上界」。這是落點範圍的保守包圍圈，不是命中機率或爆炸半徑，也不保證穿牆。資料隨已套用指令、觀測與校準更新；暫停排入但尚未執行的指令不當成新解。多選聯合射界、自動選敵／追擊目標的散布預測尚未提供。
- 榴彈砲射程遠、有最小射程、移動中不能打；要有友軍看得到目標才打得準（盲射散布加倍），同一個目標連打、看得到落點會越打越準。觀測員視野最遠、可以進駐房子。
- 車輛會互相擠開，不會疊成一台。
- 音效（R117）：預設靜音，右上音效鍵可開／關可見坦克與火砲的程序砲聲、彈著爆炸及房屋倒塌。暫停、開說明／戰報、切到背景或重開會清掉舊聲音；不播放隱藏敵軍或批次重播的歷史聲。瀏覽器不支援時仍可正常遊玩，音效不影響聲測情報、模擬或存檔。
- 戰壕（R118）：布陣列選「戰壕」，可放直段（2格／1點）、折線（3格／2點）、交通壕（4格／1點）、加固段（2格／2點）。與房屋共用8點建材，「轉向」每次90度；點壕溝任一格拿掉整段並退還，復原也可取消。相鄰段自動接線，任一方單位可穿行，速度／視線不變；命中格承傷依序75%／75%／90%／50%，與其他掩護取最強而不疊乘。只在開戰前布置，不能挖道路、泥灘、建物或單位所在格；HQ會避開已放的戰壕。壕溝的掩護是遊戲抽象，沒有本卡新增的戰時挖掘、修理或破壞。
- 鐵絲網（R121）：布陣選「鐵絲網」，2×1格可旋轉，花1點共用建材、耐久60。觀測員、步兵與徒步迫擊砲繞行，車輛可通過；不擋視線或提供掩護。榴彈砲擊可破壞，殘骸可通行。不能封死徒步通路。
- 圍牆（R120）：布陣選「圍牆」，矮磚牆／石牆／混凝土牆皆佔2×1格，可旋轉連接，花1／2／3點建材、耐久130／220／360，與房屋及戰壕共用8點。相鄰牆可接，其他建物仍隔一格；不能封死原本可達的空地。牆是可破壞建築，整段歸零才打開兩格缺口，瓦礫仍減速；矮牆也擋視線與直射，不能射越。觀測員與步兵沿用普通建築駐守及50%掩護，混凝土牆沒有碉堡的額外抗直射。沒有戰時建造、門或修理。
- 樹籬與小樹林（R116）：新局的鄉間植被可穿行，中間植被遮住視線，林緣可探頭；所在植被格使投射物傷害剩50%，與彈坑／房屋／碉堡取較強掩護、不疊乘。建房與指揮部會永久清除佔地植被，房屋倒塌不長回；舊指令紀錄不新增植被。

## 試玩看什麼（給業主的十分鐘清單）

1. 手機打開，先在路口南邊蓋兩棟磚房擋住敵方觀測員的視線，再按「開戰」。
2. 全選、點敵方坦克：看三輛坦克分開走（不疊）、地上的路線與攻擊線、草地上壓出來的車轍。
3. 把鏡頭拉近一棟正在被打的房子：屋頂炸飛、屋裡起火、倒塌時整棟沉進地面揚起一大團塵。
4. 擊毀一輛坦克：砲塔飛起來落在車旁，殘骸一直燒。
5. 打完看戰報，按「再來一局」。
6. 不下任何指令看 2–3 分鐘：電腦（預設普通）會帶坦克沿著房子掩護推進、集火、用榴彈砲配合觀測員把你打光；再試 `?ai=3`（困難）與 `?ai=1`（簡單）。
7. 開戰後用下方的生產列花補給出兵（坦克 40、榴彈砲 50、觀測員 15，補給每秒 +1）：守住右下角的指揮部（藍旗），打掉對方左上角的指揮部（灰旗）才算贏；電腦也會出兵。
8. 步兵班（一班 6 人）：選起來點一棟房子就進駐，在裡面受傷減半、可以往外打；步槍打不動坦克。拉近看人一個一個倒下。
9. 新砲：生產列的「反戰車砲」（架好才打、專打坦克，打步兵沒什麼用）和「迫擊砲」（越過房子打後面的人，兩個砲手）。試試看用反戰車砲埋伏在街角等坦克。
10. 新坦克：「輕坦克」快、看得遠，拿來找敵人；「重坦克」慢、很硬，頂在最前面；原本的「坦克」是中坦克。
11. 碉堡：布陣時多一個「碉堡」（3 點）。步兵、觀測員躲進去只吃四分之一傷害；坦克和步槍很難打壞它，要用榴彈砲或迫擊砲砸。
12. 地圖是 **1940 年的 Rye**（東薩塞克斯）：上方是敵軍登陸的 Camber 沙灘與 Rye Harbour，中間山丘上是舊城（High Street、石板路的 Mermaid Street、St Mary's 教堂、Ypres Tower、Landgate 城門），兩邊是河與泥灘（走得過但很慢），橋是要道。
13. 拉近看街景：房子有三種外牆——米白灰泥配深色木框（木構）、二樓掛紅陶瓦（掛瓦）、白色橫木板（護牆板）。
14. 鎮上的街：貼著房子有窄窄的人行道，路緣漆成黑白相間——1939–40 年燈火管制時英國真的這樣漆，讓摸黑的人看得到路邊。
15. 更多坦克（R044）：生產列多「裝甲車」（快、看得遠、打坦克很弱，拿來偵察）、「驅逐戰車」（長砲管、打坦克很痛，要停下來才能開火；車頂開放，被步兵貼近會吃虧）、「突擊砲」（低矮、正面硬，拆房子最快）。電腦（普通以上）也會出。
16. 大地圖（R043）：布陣時左上的「地圖」鍵換成 64×64 的英格蘭東南鄉間（或網址加 `?map=64`）。一條河從東北斜到西南、穿過中間的市鎮，十字大街就是橋，兩岸各一個小村；雙方各一個裝甲連起手（中坦克 6、輕坦克 2、重坦克 2、榴彈砲 3、觀測員 2），同時活著的兵最多 40。拉遠看整張圖，試試從村路的橋包抄。
17. 喪屍防守（R045）：布陣時按「喪屍」，或網址加 `?mode=zombies`；也可搭配 `?map=64`。喪屍從邊緣一波波湧來，只會近身攻擊。用掩體、火力與生產守住我方指揮部，失守後看波數、擊倒數與本機最佳紀錄。再按一次「喪屍」回一般對戰。
18. 河鎮（R130）：按「96×96 河鎮」或加 `?map=96`，進入有密集街廓、多個村莊、田野與河道的新圖；可搭配 `?mode=zombies`。原本 32／64 圖與操作保留，人口仍為每方 40；遠景與特寫使用不同幾何細節，碰撞及建築破壞資料完整保留。本輪為 Draft，尚未發布。
18. 覺得哪個效果不好，就在網址加對應的逃生閥對照（下表），告訴 Claude 要拿掉或改哪一個。

煙霧測試與 R109 真實輸入守衛需要 Chrome／Chromium（`CHROME_PATH` 可指定）。R109 守衛自行建置暫存 bundle，CI 必須實跑；本機若受 socket 權限限制會以 77 明列未跑，不當作通過。樣張存在 `shots/`（不進倉庫，CI 當附件）。R117音效守衛檢查真實WebAudio狀態、音訊圖與OfflineAudioContext輸出；既有無頭Chrome使用mute-audio，不代表已驗證喇叭音質或Android實聽。

R128 沙盒重播使用明確的 `createSandboxWorld(seed)` 初始世界；`LoggedCommand.tick` 對沙盒是指令步序（`commandTick`／`sandbox.frame`），`World.tick` 仍是戰鬥時間。`runLog` 的終點在沙盒以指令步序計，普通世界沿用戰鬥 tick。瀏覽器掛勾 `__rts.playLog(seed, log, frames, true)` 的第四參數明確選沙盒，舊的三參數呼叫不變。重置保存步序，JSON 紀錄可重播整串放置／暫停／重置；這一版沒有新增玩家存檔／匯入介面。

### 彈坑輕掩體（R106）

站在已有彈坑格的單位只承受 75% 投射物傷害，但仍受到原本彈坑減速。三種深度的減傷相同；移出彈坑就失去掩護。普通房屋與碉堡的更強掩護不再疊加彈坑效果，建築倒塌傷害不減。高爆彈先命中再挖坑，製造第一個坑的那發仍吃完整傷害。沒有新增畫面效果或開關，指令與存檔格式不變。

### 榴彈砲煙幕（R107）

選榴彈砲後，把彈種從高爆切到煙幕，再沿用砲擊方式點目標。煙幕任務最多打四發，點建築也不會一直射；混選時只有榴彈砲接煙幕命令。切回高爆後再點目標，或下新的移動、攻擊、停止命令即可換任務。

煙幕不傷人、不拆房、不挖坑，只遮住雙方視線。每團半徑 2 格，維持 20 秒，隨該局固定風向緩慢漂移；最多同時 8 團，超過時移除最舊一團。繞到另一側的友軍仍能觀測，已知座標也仍可盲射，煙幕擋不住炮彈。煙團與風都記在世界裡，讀取與重播不會憑空消失。

### 反砲兵粗略情報（R115）

敵方榴彈砲或迫擊砲真正開火後，小地圖會出現橙色虛線的「疑似敵砲區」。這是砲聲線索，不是敵軍位置標記：不會打開迷霧、顯示敵砲模型或把點擊變成精確鎖定。可以沿用小地圖點擊移鏡，再選擇盲射壓制，或讓觀測員前去確認。

同一個2×2格子區連續開火，估計範圍分三階縮小；橢圓半軸為8×6、4×3、2×1.5格，第三階仍保留位置不確定性。每個8×8粗區只記最近聲源，不辨認是哪一門砲；不同砲在區內交替開火可能讓估計重新變寬。同時開火有固定子區優先順序，沒有因單位ID洩漏位置。

線索自最後一發起維持30秒（暫停時不倒數），每方最多8區。沒再開火時，敵砲悄悄移動或被擊毀都不會即時改變舊圈；換區後重新開火才給新線索。煙幕發射也有砲聲。全32格戰場接收聲測與上述數字是二戰聲測概念的玩法抽象，不代表真實器材精度。

雙方情報都進入決定性世界與重播；本卡只提供玩家介面，沒有修改電腦對手。敵砲換陣地與AI使用情報由Claude線另做。
