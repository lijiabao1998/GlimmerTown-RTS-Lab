## 怎麼玩

遊戲裡右上角的「？」也有一份說明。

1. **布陣**：開局停在第 0 步。點藍色的我方半場蓋房子當掩體——農舍 1、磚房 2、穀倉 3，建材共 8；「轉向」轉磚房、「復原」拿掉最後一棟、點蓋好的房子也能拿掉。不能蓋的地方提示列會寫原因。
2. **開戰**：按「開戰」。敵人也會在他那半邊蓋房子。
3. **選取**：點我方單位（藍圈）；「全選」選全部。受傷或被選中的單位頭上有血條，提示列顯示平均血量與各自在做什麼。
4. **下指令**：點地面＝移動；點敵人（紅圈）＝攻擊；點房子＝轟它；「砲擊」模式下點地面＝榴彈砲對那一格開火。選中的單位地上會畫路線（綠）、攻擊線（紅）、砲擊準星（橘）。
5. **結局**：一方全滅時慢動作、鏡頭移到最後一擊，接著出戰報（擊毀、損失、轟塌、開火、你蓋的房子還站著幾棟）；「再來一局」回到布陣。

- 手勢：單指拖曳平移（放手會滑一段）；雙指捏合縮放（對準手指）；雙擊我方單位＝鏡頭跟過去。桌機：右鍵下指令、滾輪縮放（對準游標）、空白鍵暫停、Esc 取消選取。
- 坦克被房子擋住時，砲彈打在房子上。房子三段損壞：完好 → 沒屋頂的空殼（起火、冒煙）→ 瓦礫（可以走、不擋射線）。
- 榴彈砲射程遠、有最小射程、移動中不能打；要有友軍看得到目標才打得準（盲射散布加倍），同一個目標連打、看得到落點會越打越準。觀測員視野最遠、可以進駐房子。
- 車輛會互相擠開，不會疊成一台。

## 試玩看什麼（給業主的十分鐘清單）

1. 手機打開，先在路口南邊蓋兩棟磚房擋住敵方觀測員的視線，再按「開戰」。
2. 全選、點敵方坦克：看三輛坦克分開走（不疊）、地上的路線與攻擊線、草地上壓出來的車轍。
3. 把鏡頭拉近一棟正在被打的房子：屋頂炸飛、屋裡起火、倒塌時整棟沉進地面揚起一大團塵。
4. 擊毀一輛坦克：砲塔飛起來落在車旁，殘骸一直燒。
5. 打完看戰報，按「再來一局」。
6. 覺得哪個效果不好，就在網址加對應的逃生閥對照（下表），告訴 Claude 要拿掉或改哪一個。

## 逃生閥對照（網址參數）

每個閥只關畫面或介面，模擬雜湊不變；可以疊加，例如 `?noR004=1&noR008=1`。

| 參數 | 關掉什麼 |
|---|---|
| `?fx=off` | 所有爆炸、煙、火、碎片（R001、R004） |
| `?noR004=1` | R004 破壞的重量（回到 R001 的小爆炸）：倒塌殘影、碎片、火、曳光、砲塔飛起、鏡頭震動 |
| `?noR006=1` | R006 開局布陣：開頁直接開打 |
| `?noR008=1` | R008 車輛有重量：車轍、行進揚塵、開火後座、砲塔平滑轉向、受擊閃光 |
| `?noR009=1` | R009 血條與耐久條 |
| `?noR010=1` | R010 結局慢動作、鏡頭移動與戰報（回到「勝利」橫幅） |
| `?noR011=1` | R011 指令回饋：路線、攻擊線、砲擊準星 |
| `?noR012=1` | R012 鏡頭手感：縮放對準手指、拖曳慣性、雙擊跟上 |
| `?noR014=1` | R014 牆上的彈孔與高爆彈燻黑 |
| `?noR015=1` | R015 小地圖 |
| `?noR016=1` | R016 開戰儀式：布陣的房子從地面升起、「開戰！」大字 |
| `?noR100=1` | R100 戰爭迷霧（看得到全部敵人） |
| `?noR101=1` | R101 觀測員的細節模型 |
| `?seed=` | 換地圖（預設 1944） |
| `?px=3` | 渲染解析度 1/3（對照畫風 A） |

## 開發

```bash
npm ci
npm run dev        # 開發伺服器（埠 8401）
npm run check      # 型別 → Node 守衛 → 建置單檔 → 無頭 Chrome 煙霧測試
```

煙霧測試需要 Chrome／Chromium（`CHROME_PATH` 可指定）。樣張存在 `shots/`（不進倉庫，CI 當附件）。
