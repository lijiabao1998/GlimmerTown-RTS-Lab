## Claude 線的技術標準（R003）

業主 2026-10-17：「讓Claude自己決定技術標準並且做完善，要有驚艷的感覺」。下面是 Claude 自己定的門檻，**約束 Claude 的卡（R001–R099）**；GPT 車道照 `AGENTS.md`，不受本節約束（可以參考）。本節不加守衛、不改 GPT 車道白名單與合併條件。

仍等業主、本節不碰：調高手機預算、畫風、後製（`src/render/post.ts`）、整體光源、鏡頭角度與能不能轉、離開二戰。

### 一、目標：三件「一眼看得出來」的事

1. **破壞看得出重量**：房子不是瞬間換模型，是被打爛的過程；打爛的痕跡留到整局結束。
2. **每一發都有因果**：開火 → 飛行 → 命中 → 餘波，四拍都看得到，看得出誰打誰。
3. **單位像實體**：車不疊車、走位看得懂、指令當下就有回饋。

### 二、架構分層

| 層 | 規矩 |
|---|---|
| 模擬 `src/sim` | 整數、決定性（`AGENTS.md` 規則 2）。新機制寫成「每一步從世界重算」，或「狀態放進 `World` 並折進雜湊」；不准模組變數藏狀態。只加不改的欄位只在有值時折進雜湊，舊世界的雜湊才不變。 |
| 渲染 `src/render` | 只讀世界。效果由模擬事件（`fire`／`impact`／`stage`／`kill`／`build`）驅動，時間軸用模擬時間（暫停就凍結）；亂數只用 `hash2`，不用 `Math.random`、不用現實時間——同一場戰鬥同一刻截兩次圖，效果一模一樣。 |
| 效果系統 `src/render/fx.ts`（R004 建） | 固定容量的池（struct-of-arrays），每幀零配置；一個池＝一個 InstancedMesh＝有實例時 1 次繪製呼叫；池滿丟最舊的。新效果加進既有的池，不另開網格。 |
| 介面 `src/ui`、`main.ts` | 只發指令。要預覽（例如布陣），用世界的複本跑**同一支**模擬函式，不另寫一份規則。 |

### 三、每張卡的品質門檻

1. `npm run check` 四步本機全綠。本機 Node 低於 22.18 時，unit 與 smoke 用 `npx -y node@24` 跑；跑不了就照實寫「未跑，靠 CI」。
2. **改模擬**：寫 `tests/<主題>.mjs`，涵蓋行為、指令紀錄 JSON 來回重播、中途 `structuredClone` 接著跑；每條守衛故意弄壞一次，第一個紅燈落在它身上（`tests/*.mjs` 排在黃金雜湊之前跑，R005）。
3. **改畫面**：煙霧測試加一張「特寫」樣張——效果正在發生的那一刻，固定 tick、固定鏡頭；卡面寫看到什麼。逃生閥 `?noR<號>=1` 關掉後回到舊樣、雜湊不變。
4. **預算**（不調高）：手機 412×860 開局繪製呼叫 ≤ 20、三角形 ≤ 80,000；戰鬥最熱的特寫時刻繪製呼叫 ≤ 22、三角形 ≤ 80,000。煙霧測試量，不靠估。
5. **每幀不配置**：每幀、每粒子的路徑不 `new` 物件；用池和暫存物件。
6. **對抗式審查**：推 PR 前，獨立審查各看一個面向（決定性與規則、驗收與品質），每個發現再嘗試反駁；確認的修掉，駁回的寫進卡面。審查代理卡住就由 Claude 自己逐條審（業主 2026-10-18）。
7. **誠實**：沒跑過的不寫「通過」；「沒做成的事」照實寫，不美化。

### 四、驚艷門檻（畫面卡）

1. **命中三拍**：閃光（≤ 0.1 秒）→ 火球／震波（0.3–0.5 秒）→ 餘韻（煙、塵、火 3 秒以上）；焦痕、瓦礫、殘骸留到整局結束。
2. **倒塌有過程**：房子倒成瓦礫時，舊模型約 1 秒內抖動、傾斜、沉進地面，同時揚塵；碎片顏色取自那棟房子的牆與屋頂。
3. **擊毀**：坦克的砲塔飛起、翻滾、落在車旁留到整局結束；殘骸起火後冒黑煙。
4. **光感不靠加燈**：用加色混合的光暈與火光；不加動態光源（不換整體光，也不在戰鬥中重新編譯著色器）。
5. **鏡頭震動有上限**：只在畫面附近的大爆炸，幅度 ≤ 0.08 格、≤ 0.4 秒；只加在畫面那一趟，不影響點選；跟著效果的逃生閥一起關。
6. **戰爭迷霧不洩漏**：射擊線索（開火、彈著、擊毀）在看不到的地方不畫；建築的損壞本來就看得到，它的煙火可以畫。

### 五、手感門檻（玩法卡）

1. **不疊**：兩輛車靜止後中心距離不小於兩者半徑和（整數容差 2）。
2. **不卡死、不進牆**：推擠不把車推進建築或地圖外；窄巷對向也過得去。
3. **指令回饋**：下指令的同一幀出現地面標記；不能做的事在提示列寫原因（不是沒反應）。
4. **觸控**：按鈕至少 44×44 CSS 像素；手機 412×860 上不互相遮住。
