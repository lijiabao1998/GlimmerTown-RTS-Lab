## 為什麼做這張

R083 留下的 `defaultRelay()` 寫著：

```ts
return location.protocol === 'http:' && location.host ? `ws://${location.host}/relay` : 'ws://127.0.0.1:8788/relay';
```

所以玩家從 GitHub Pages（`https://lijiabao1998.github.io/GlimmerTown-RTS-Lab/`）或 `https://game.lijiabao.uk` 開啟遊戲時，預設會去連自己電腦上的 `ws://127.0.0.1:8788/relay`；沒有在本機先啟動 `node server/relay.mjs` 就開不了房，也不能直接把分享連結傳給異地的另一位玩家。

這張用業主自己的個人 Cloudflare 帳號（`lijiabao1998@gmail.com`／`lijiabao1998.workers.dev`，Free 方案支援 SQLite-backed Durable Objects）部署零外部依賴的公開轉發伺服器 `glimmertown-rts-relay`，並讓 HTTPS 遊戲頁預設連到這個 `wss://` 轉發位址，開網頁免自架即可開房合作或對戰。

## 做什麼

1. **新增 `server/cf-relay/`（零外部依賴、不加 `package.json` 依賴）**：
   - `wrangler.toml`：Worker 名稱 `glimmertown-rts-relay`、`compatibility_date = "2026-01-01"`、`workers_dev = true`，綁定 SQLite-backed Durable Objects `ROOMS`／`RelayRoom`（`new_sqlite_classes = ["RelayRoom"]`），設定 `ALLOWED_ORIGINS`（允許 `https://lijiabao1998.github.io`、`https://game.lijiabao.uk`、`https://lijiabao.uk`、`http://localhost`、`http://127.0.0.1`）。
   - `src/relay-core.js`：與 `cloudflare:workers` 解耦的核心轉發邏輯，讓 Worker 與 Node 24 測試共用同一份實作；支援：
     - `GET /`、`GET /health` 回傳 `200` JSON `{ ok: true, service: 'glimmertown-rts-relay' }`；
     - `GET /relay?room=<1–12 英數字>&role=host|join` WebSocket 升級與 Origin 檢查；
     - 與 `server/relay.mjs` 一致的訊息協定（`welcome`、`joined`、`left`、`error`、`from` 標籤、`MAX_MESSAGE = 256 KB`、只轉發非陣列 JSON 物件、房主離線即關房）；
     - 基於 Durable Object WebSocket Hibernation attachment 的防串房世代編號（`gen = Math.max(Date.now(), this.lastGen + 1, maxExisting + 1)`），即使 DO 休眠重啟也不會讓舊客端串進重開的同一房號。
   - `src/index.js`：`RelayRoom extends DurableObject` 薄殼與 Worker `fetch` 入口。
   - `README.md`：記錄 Cloudflare Dashboard Git 整合部署設定（根目錄 `server/cf-relay`、無須建置指令、`npx wrangler deploy`）、免費額度說明與協定。
2. **更新 `src/net/client.ts`**：
   - 新增匯出 `export const PUBLIC_RELAY = 'wss://glimmertown-rts-relay.lijiabao1998.workers.dev/relay';`（`wss://` 協定，符合 `tools/unit.mjs` 零外部 `http(s)://` 素材掃描）。
   - `defaultRelay()` 照舊先讀取 `localStorage['gtrts.v1.relay']`；沒存過時，若 `location.protocol === 'https:'` 則回傳 `PUBLIC_RELAY`；`http:` 本機頁與 `file://` 完全照舊。
   - 更新連線面板文字提示，說明 HTTPS 頁免自架預設連公開轉發伺服器，仍可透過 `node server/relay.mjs` 或 `?relay=` 切換自架。
3. **新增守衛與文件**：
   - `tests/relay-public1012.mjs`：測 `defaultRelay()` 四種協定／儲存情境、Origin 白名單、`handleRelayRequest` 路由與拒絕、以及 `RelayRoomCore` 完整雙人開房／加入／滿房／雙向轉發／房主離線關房／休眠防串房協定。
   - 更新 `LOG.md` 與 `README.md`（說明 HTTPS 線上版預設免自架連線，並補記 `server/cf-relay/`）。
