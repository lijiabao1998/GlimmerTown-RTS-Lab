## 為什麼做這張

手機上最常做的事是移動鏡頭。現在雙指捏合與滾輪都是對著畫面中心縮放——想放大看手指下的那棟房子，放大完它就跑出畫面；拖曳一放手就硬停，滑長距離要拖很多次。這是「操作起來順不順」的第一印象（R003 手感門檻）。

## 做什麼（只改鏡頭與輸入，不改模擬）

1. **縮放對準手指／游標**：滾輪縮放時游標下的地面點不動；雙指捏合時兩指中點下的地面點不動（縮放範圍照舊 0.55–3）。
2. **拖曳慣性**：單指拖曳放手時帶著最後的速度繼續滑，約 0.5 秒內停下；碰到地圖邊就停在邊上。按下去任何一指立刻停。
3. **雙擊我方單位**：鏡頭在 0.4 秒內平移到那台車（同時照舊選取它）。
4. 純邏輯放在 `src/ui/camera.ts`（慣性衰減、平滑移動的數學，不碰 DOM），Node 可以測。
5. **逃生閥** `?noR012=1`：回到 R011 的鏡頭行為；雜湊不變。
