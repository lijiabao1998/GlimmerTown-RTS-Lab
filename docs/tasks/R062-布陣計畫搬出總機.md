## 為什麼做這張

整理計畫第 3 步：被守衛「切原文」的 `main.ts` 邏輯搬成可以 import 的小模組。R060 時量到 40 支守衛錨在 `main.ts` 原文 176 行上，`main.ts` 一動，不相干的守衛就紅。

第一批搬布陣：`main.ts` 裡布陣計畫那一段（計畫、選中的種類與方向、建材、預覽、點地面放下／拿掉、提示文字、布陣列的四樣設定）約 60 行，被 `trenches-ui`、`walls-ui` 兩支大守衛整段切進沙箱跑，另有 `trenches-browser`、`walls-browser`、`wire-browser`、`materials-view` 錨在它的原文上。

## 做什麼

1. 新模組 `src/ui/buildPlanner.ts`：`BuildPlanner` 類別（`plan`、`pickKind`、`pickRot`、`pickTrench`、`trenchRot`、`buildHint` 與 `previewWorld()`、`refreshPreview()`、`pointsLeft()`、`placeAt()`、`clear()`、布陣列的 `barItems()／barActions()／barTrenches()／barWalls()`），外部東西（世界、畫面、現在是不是布陣、重畫）由建構時傳進來。程式逐行搬，規則不改。
2. `main.ts` 只建一個 `planner` 並接線：開局 `planner.clear()`、開戰 `for (const c of planner.plan) issue(c)`、布陣時點地面 `planner.placeAt()`、HUD 提示、布陣列一行 `initBuildBar(planner.barItems(), …)`。
3. 守衛：`trenches-ui`、`walls-ui` 改建真的 `BuildPlanner`（從原文載入，故意弄壞的突變照樣能套），不再切 `main.ts` 的布陣原文；開戰、開局、紀錄那幾段仍切 `main.ts`（下一批再搬）。瀏覽器守衛的突變改錨到 `buildPlanner.ts`。其他夾具給一個假的 `planner`。

## 不改什麼

## 施工紀錄

- 新檔 `src/ui/buildPlanner.ts`（123 行）：`BuildPlanner` 類別與布陣用的常數（`TRENCH_LABEL`、`TRENCH_SHAPE`、`BUILD_LABEL`、`BUILD_TIP`、`buildWhy()`）。程式逐行從 `main.ts` 搬來，只多了 `this.` 前綴；外部的世界、畫面、是否布陣中、重畫、畫面大小由建構時傳進一組小函式（`PlannerEnv`），四個閥（R118、R120、R121、R105）與可蓋的種類由設定傳進來（`PlannerOptions`）。
- 這個專案的 TypeScript 只准「可直接拿掉型別」的寫法，建構子不能用參數屬性，所以欄位一個一個寫出來。
- `main.ts` 718→653 行：只剩建 `planner` 一段與接線（開局 `planner.clear()`／`refreshPreview()`、開戰 `planner.previewWorld()` 與 `for (const c of planner.plan) issue(c)`、布陣時點地面 `planner.placeAt()`、HUD 提示、布陣列一行）；搬走後用不到的 import 一併拿掉。
- 守衛 17 支跟著改：
  - `trenches-ui`、`walls-ui` 從原文載入真的 `BuildPlanner`（突變直接套在 `buildPlanner.ts` 原文上），夾具裡原本的 `plan`、`pickKind` 等變數改成轉接到 `planner` 的欄位，斷言一句沒改。
  - 九支切 `main.ts` 跑的 Node 守衛給一個假的 `planner`（只有它們會碰到的那幾個方法）。
  - `materials-view` 原本在 `main.ts` 找 R105 接到布陣說明那一句，改成找 `materials: V.r105` 與 `buildPlanner.ts` 裡那一句。
  - 瀏覽器守衛（`trenches-browser`、`walls-browser`、`wire-browser`）注入的觀測程式改讀 `planner.*`，突變錨到 `buildPlanner.ts`；`audio-browser`、`vegetation-browser` 重設計畫那一句改成 `planner.plan = []`。
- 第一次本機跑新紅 3 支（`audio-browser`、`trenches-browser`、`walls-browser`）：注入的觀測程式用到 `BK_COTTAGE`、`applyTrench`、`isWallKind`，這些名字搬家後 `main.ts` 不再 import。加一個小工具：缺哪個名字才在注入時補 import，修好後三支重跑綠。
