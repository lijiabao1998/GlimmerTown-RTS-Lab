## 為什麼做這張

業主 2026-11-16：「细化房屋美术水平，增加更多房屋」。R086 把現有五種房子做細了；這張讓鎮上真的多出房子，而且多出幾種這一帶才有的：萊伊在英格蘭東南（肯特、薩塞克斯一帶的威爾德），1940 年的鄉下最顯眼的是**啤酒花烘房**（磚砌的圓形烘爐、圓錐頂、白色風帽）、**塔式風車**（白色木板塔身、四片風帆），萊伊港邊則是**塗焦油的木板倉庫**（高三層、頂樓有吊貨的小屋）。

設計先跑了一個工作流（三份方案＋裁判）：「只換外觀」不加房子；「另開一張新地圖」玩家在預設的局裡看不到；選的是「新開的局都加」那一份——跟 R084 的 `sym` 一樣，新開的局 `map` 指令多帶一個 `more: 1`，舊重播、舊存檔一模一樣。

這一類遊戲裡房子是掩體、是可以駐守的據點、是被打塌的東西（R088 建築破壞的過程要用到）；地圖上有地標，玩家才認得路。

## 做什麼

**一定要做**

1. **三種新房型**（模擬裡的新種類；材質決定耐久與彈道，跟既有的房子一樣能駐守、擋視線、被打塌）：
   - `BK_OAST`＝11 **啤酒花烘房**（磚）：2×1 或 1×2、兩層。看得到的那一頭是八角形的烘爐（直徑 0.60、牆高 0.66、`0x8e5040`），上面圓錐頂（再高 0.55、`0x5e3a2e`）、白色風帽（`0xe0dacb`、開口朝鏡頭那邊是暗色），風帽頂在 1.40–1.50；另一頭是兩層的儲藏間（一樓磚、二樓可以是木板）、正面一個裝貨門。
   - `BK_MILL`＝12 **塔式風車**（木）：1×1、三層。磚砌的八角基座、往上收的八角白色木板塔身（0.62 → 0.40、到 1.35）、帽子、四片風帆排成 X（帆面朝鏡頭；最低的帆尖不低於 0.95、伸出格子最多 0.15）。
   - `BK_WAREHOUSE`＝13 **河岸倉庫**（木）：1×2 或 2×1、三層（牆高 1.18）。一樓磚、上面塗焦油的木板（`0x2f2b28`）、頂樓吊貨小屋、至少三扇上下疊的裝貨門。
2. **`more` 旗標**：`map` 指令多一個 `more: 1`（只在第 0 步、只看第一個 `map` 指令）；世界多一欄 `more`，只在有時折進雜湊；存檔編碼帶著它；指令檢查收整數。
3. **放房子**（`src/sim/moreHouses.ts` 的 `applyMoreHouses`）：只在 `more` 的局、第 0 步、套完地圖之後跑；不碰世界的亂數（自己的一條，種子 `w.seed ^ 0x52303837`）；只往後加建築（萊伊另外把河邊 Strand 的三棟穀倉改成倉庫，id 與佔地不動）。
   - 萊伊、丘陵：手排的表（不抽亂數）。萊伊：河西岸草地上一座風車＋三棟倉庫；丘陵：一對風車、一對烘房（點對稱）。
   - 村莊、64、96：成對放（點對稱的另一格也要能放），風車、烘房、填空的住宅與小屋；不放在路、泥、植被、已佔的格上；離地圖邊 ≥ 2 格；四周一圈空著；不進開局角落（32 圖 8×8、64／96 圖 12×12）；離每個單位 ≥ 2 格；放了之後路還是通的。
   - 數量（種子 1944）：村莊 +6、64 +12、96 +20（種子 0–49 的最少值也寫進守衛）。
4. **畫法**（`src/render/moreArt.ts`）：完好、空殼、瓦礫、96 圖遠景兩層；配色照 R086 的規則（`hash2(b.id, k, 87)`）。畫面的閥關掉時新房型照「看起來像的舊種類」畫（烘房像住宅、風車像小屋、倉庫像穀倉），模擬不變。
5. **接線**：閥 `?noR087=1`（新開的局不帶 `more`、不畫新模型）；`tools/cdp.mjs` 的守衛預設加 `noR087=1`（跟 R069、R076 一樣：既有的瀏覽器守衛照舊測沒有 R087 的局），要測 R087 的傳 `{ r087: true }`。

**做得完才做**：96 圖河邊兩對 2×2 倉庫；64、96 圖的 3×1 雙烘爐烘房；風車尾舵。

## 驗收（動手前寫）

1. **卡面先**：第一個提交只有這張卡。
2. **舊的一模一樣**：黃金雜湊（Node 與 Chrome）；每一張地圖凍結的雜湊不變；動模擬之前先凍結一張「電腦對電腦」的表（地圖 0–4、種子 1944、3000 步、`sym` 0／1），改完一樣；在 `139f2fb` 錄的紀錄（地圖 0–4、喪屍、對戰）R087 開關都重播到同樣的第 600 步雜湊；既有守衛一支都不改（`tools/cdp.mjs` 加預設閥除外）。
3. **不抽世界的亂數**：`more: 1` 時地圖 0–4 × 種子 0–49，第 0 步之後的 `w.rng` 跟沒帶時一樣；地形、植被、彈坑一樣；既有的建築一棟都沒變（萊伊那三棟改成倉庫的除外：種類 13、三層）。
4. **頁面等於重播**：在沙盒裡跑真的 `reset()`（`V.r087` 開），第 0 步之後的世界跟 `runLog` 一樣（雜湊、欄位順序），地圖 0–4 × `sym` 0／1 × 兵力 1／2／3、地圖 1、2 的喪屍；Chrome 裡五張地圖第 0、600 步的雜湊等於 Node 重播頁面自己的紀錄。
5. **數量**（種子 1944，與種子 0–49 的最少值）：照「做什麼」第 3 條；村莊、64、96 每一棟新的都有點對稱的另一棟（同種類、同佔地）；丘陵整個點對稱。
6. **放得安全**：第 3 條的每一個規則都成立；每一棟新房子的入口從兩邊的指揮部都走得到；有沒有 `more` 指揮部的格子都一樣（種子 0–49、地圖 0–4、`sym` 0／1）。
7. **布陣還有地方**：`more: 1` 時電腦的布陣（兩張表）花完 8 點的種子數不比沒帶時少；每一種能布的東西在每張地圖上至少有 20 個合法的我方位置；沒有 `more` 時電腦的布陣逐位一樣。
8. **模擬的性質**：材質與耐久照「做什麼」第 1 條；三段損壞、擋視線、駐守都走通用的；`build` 指令收到 11–13 回 `kind`；指令檢查不收非整數的 `more`；存檔編碼來回一樣；R087 的存檔第 300 步存、讀回來雜湊一樣；舊的存檔照樣讀得到。
9. **閥**：`?noR087=1` 時五張地圖第 0、600 步的雜湊等於 R087 之前；帶 `more` 的紀錄在閥關著時照樣重播到同一個雜湊、用替代的樣子畫、頁面錯誤 0。
