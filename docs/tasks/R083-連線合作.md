## 為什麼做這張

業主 2026-11-16 的目標裡「要求包含在线联机功能」（R082）。這個模擬是決定性的、只靠指令推進（同一個種子＋同一串指令＝同一局，重播就是這樣做的），最適合**鎖步**：每個人只把自己下的指令送給對方，兩邊各自跑同一個模擬。第一步先做合作——兩個人一起指揮我方打電腦——因為介面與畫面有上百處寫死「我方是第 0 方」，換成「我方可以是第 1 方」是下一張（R085）的事；合作不用換，先把同步做穩。

## 做什麼

### 1. 轉發伺服器 `server/relay.mjs`

- 零依賴（只用 Node 內建的 `http`、`crypto`、`fs`、`path`），一個檔案：`node server/relay.mjs`（預設埠 8788，`--port` 或環境變數 `PORT` 可以改）。
- HTTP：伺服 `dist/` 的遊戲頁（先 `npm run build`）。同一個區域網路裡的人開 `http://<這台電腦的位址>:8788/` 就能玩；沒有 `dist/` 時回一行說明。
- WebSocket `/relay?room=<房號>&role=host|join`：房間最多 2 人。`host` 開房（房號已經有人用就拒絕）、拿 0 號；`join` 加入已經開好的房、拿 1 號（沒有這個房、或滿了就拒絕）。一個人送的訊息原樣轉給同房的另一個人（加上 `from`），不轉給自己；有人進來、離開通知另一個人；房主離開時房間關掉。
- 不存世界、不存紀錄、不懂遊戲規則：它只轉訊息。

### 2. 鎖步 `src/net/lockstep.ts`（純邏輯，不碰網路、不碰畫面）

- 每走一步（第 t 步，t ≥ 1），每個玩家送一包「第 t＋延遲 步要執行的指令」（沒有指令也送空包）。延遲 4 步（0.2 秒）。第 1～4 步兩邊都預先當成空包。
- 第 t 步要等兩個玩家的包都到了才走；指令照玩家編號、再照下的先後合在一起。網路亂序、晚到都不影響結果。
- 每 100 步，兩邊各自算一次世界雜湊、送給對方；不一樣就停在那一步，說「不同步」。
- 對方離線：從對方最後一包之後，不再等他（自己繼續打，電腦照舊）。

### 3. 連線 `src/net/client.ts`

- 開房的人（0 號）照平常開局、布陣；按「開戰」那一刻（第 0 步）把種子與第 0 步的指令（地圖、規則、補給、電腦、雙方布陣）送給對方，第 1 步起進入鎖步。
- 加入的人（1 號）收到之後，照**重播**那一條路建世界：同一個種子、第 0 步餵房主的那串指令（重播本來就逐位一樣，R047）。
- 連線的局，指令紀錄照實際執行的那一步記：打完存的重播重播得出來。

### 4. 介面

- 開始選單多一顆「連線合作」：一頁有伺服器位址（預設：遊戲頁是由轉發伺服器給的就用同一台；網址可以帶 `?relay=`）、房號（開房時隨機 4 碼）、「開房」「加入」。
- 開房之後照平常按「開始」布陣、按「開戰」；對方還沒進來就開戰＝單機打（對方再進來會說「已經開打了」）。
- 加入之後顯示「已加入，等房主開戰…」，房主開戰就自動進入同一局。
- 右上一行狀態：房號、幾個人、來回延遲；等對方的包超過半秒顯示「等另一位玩家…」；不同步、對方離線也寫在這一行。
- 兩個人都指揮我方（第 0 方）：選取各自的；生產佇列、補給共用。暫停：任何一方暫停（打開選單），另一方就在等——等於一起暫停。

### 5. 逃生閥 `?noR083=1`

沒有「連線合作」鍵；網址的房號不理。

## 不改什麼

- 模擬（`src/sim`）一行都不改；黃金雜湊、舊重播、存檔不受影響。
- 沒有連線的局：`tick()` 用的指令照舊（`pending`／重播），一模一樣。
- `main.ts` ≤ 673 行（把幾行沒有守衛碰到的併起來，騰出要加的兩行）、`battle.ts` ≤ 1195 行。

## 不做（後面的卡）

對戰（另一個人指揮另一方，R085）；開打之後才加入；斷線重連；三人以上；放上網的主機（等業主）。

## 驗收（動手前寫）

**單機不變**

1. 黃金雜湊 `eea1d59b`；全部既有守衛綠。
2. 沒有連線時，`tick()` 送進模擬的指令跟改之前一樣（Node：直接比對指令來源的那一行在沒連線時回傳 `null`）。

**鎖步（`tests/net-lockstep.mjs`，Node）**

3. 兩個模擬的玩家各自一個世界（萊伊、雙方第三版電腦之外，兩個玩家都對我方下指令），每個包延遲 0–300 毫秒、亂序到，雙方隨機下指令走 2,000 步：每一步兩邊的雜湊都一樣；兩邊的指令紀錄一樣，拿去 `runLog` 重播得到一樣的雜湊。
4. 等：一方的包沒到，另一方不走那一步。
5. 合在一起的順序照玩家編號、不照到達的先後（反過來到也一樣）。
6. 不同步：偷偷改一邊的世界，下一次比雜湊兩邊都說「不同步」、停在那一步。
7. 離線：一方離開之後，另一方從對方最後一包之後繼續走、不卡住。

**伺服器（同一支，真的開一個 `server/relay.mjs` 行程）**

8. 開房拿 0 號、加入拿 1 號；訊息轉給對方、不轉給自己；第三個人進不來；沒有的房號加不進去；同一個房號不能開兩次；不同房間互不相通；有人離開通知對方；房主離開房間關掉。
9. HTTP：有遊戲頁時給 `index.html`；沒有時回說明。

**瀏覽器（`tests/net-browser.mjs`，兩個真的 Chrome＋本機的轉發伺服器）**

10. 房主開房、對方加入；房主開戰，對方進入同一局（同一個種子、同一張圖）。
11. 雙方各下一個移動指令；兩邊都走過 300 步以上、雜湊比過至少兩次、沒有不同步。
12. 兩邊的指令紀錄拿去 Node 重播，到同一步的雜湊一樣，也等於兩頁自己算的。
13. `?noR083=1` 沒有「連線合作」鍵。

**其他**

14. 每一條守衛故意弄壞一次（Node 用隔離副本；瀏覽器用休眠的故意弄壞），第一個紅燈落在它身上。
15. README：怎麼開伺服器、怎麼連、限制；閥表。`main.ts` ≤ 673、`battle.ts` ≤ 1195。
