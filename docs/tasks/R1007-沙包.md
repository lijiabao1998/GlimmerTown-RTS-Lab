## 為什麼做這張

R050 第一段只做了後方的三種建築；卡面「沒做成的事」第 2 條留下「沙包、修橋、排雷、指揮部升級」。這四樣裡，沙包是唯一不用新地圖物件、不用新單位就做得出來的：地圖上的橋只是「路蓋過泥灘」，沒有可以炸、可以修的橋；遊戲裡也沒有地雷。修橋、排雷、指揮部升級各要一套新規則，留給以後。

現在場上的掩護只有兩種來源：

- 地圖本來就有的（房子、樹林、彈坑）；
- 開戰前第 0 步布陣挖的壕溝（R118 `trenchError` 第一句就是 `if (w.tick !== 0) return 'tick';`）。

仗一打起來、戰線一動，機槍組、反戰車砲停下來架好的地方就沒有任何掩護。工兵現在只會拆（R1002）和在後方蓋房子（R050）。1940 年英國防守方真正在做的事，是在路口、橋頭、碉堡旁邊臨時堆沙包陣地（R090 的海斯地圖就是皇家軍事運河那一道防線）。路線圖原本把「沙包陣地（站在裡面有掩蔽、不擋路）」列在 R024b（`docs/ROADMAP.md` 第 284 行；R024 卡面「沒做成的事」）；這張先做戰中由工兵堆的那一種，布陣時的版本與龍牙照舊留在 R024b。

## 做什麼

### 1. 存在哪裡：為什麼不用壕溝的表、也不用鐵絲網的表（讀過程式碼之後）

**不放進 `w.trenches`（R118）：**

- `TrenchSegment` 只有 `{ side, kind, x, z, rot }`，沒有血；R118 卡面明寫「沒有戰時挖壕、戰壕血量／修復／破壞」。沙包一定要打得壞。
- `trenchError` 只在第 0 步、只在自己半場、要扣布陣的 8 點建材；這三條都不適用戰中。
- 加 `TRENCH_KINDS` 第 4 種會讓 `trenchKind(4)` 從 `null` 變成有：一份舊紀錄如果有 `{ t: 'trench', kind: 4 }`，以前回 `'kind'` 被拒、以後會被接——舊紀錄重播就變了。
- 壕溝是刻進地面貼圖的（`render/trenches.ts` 的 `FLOOR[kind]` 表只有 4 格），每次 `trench` 事件整張地面重刻（`battle.ts` 第 495–498 行，海斯 128×128 就是 16,384 格）；戰中每堆一處沙包就整張重刻太貴。
- `trenchCover` 對所有兵種都打折（坦克站在壕溝裡也只吃 75）；沙包只該護著人和砲。

**不放進 `w.wires`（R121）：**

- 好處是現成的：`Building` 形狀、有血、`land()` 已經有一段高爆打網的迴圈、R1002 的爆破走得到它。
- 但 `wireAt()` 不看種類，每一個呼叫它的地方都把找到的東西當鐵絲網：`wireBlocks`（徒步單位走不進去——沙包一定要走得進去）、`eco.ts` 的 `hqSpot` 與 `spawnCell`、`build.ts` 的 `buildError` 與 `keepsFootPaths`、`trenches.ts` 的 `trenchError`、`tech50.ts` 的 `why50`（兩處）、`pointsUsed` 把每一段都算 1 點建材、喪屍把每一段當攻擊目標（`zombies.ts` 第 59 行）、`smoke.ts` 點到就叫工兵去剪、`wireGeo` 把每一段畫成鐵絲網、`view98.ts` 的屋頂鍵。要在十來個地方加種類判斷，其中好幾行被守衛錨著（`wire-negative`、`engineer1002-negative2` 的 `route_wire`）。

**不放進 `w.blds`／`occ`（像 R050 那樣）：** `blocks()` 會讓它擋路、擋視線、擋射線；只有 `garrison` 的兵種進得去，機槍組（`garrison: false`）進不去——機槍陣地正是沙包最該護的。

**所以：新的一張表 `w.bags?: { version: 1; segments: (Building & { left: number })[] }`。** 形狀照抄鐵絲網（`Building`：`id, kind, x, z, w, d, floors, hp, maxHp, builtBy`），多一欄 `left`（還差多少工作量，0＝蓋好，跟 R050 的 `w.tech.sites[].left` 同一個意思）。照抄 `Building` 是為了直接重用 R1002 的 `near1002`／`demo1002`（它們吃 `{ x, z, w, d, hp }`）。掛勾的位置跟鐵絲網、壕溝一模一樣：`land()` 高爆那一段、`damageUnit` 算掩護那一段、`morale.ts` 的 `coverPct`。

#### 3.4 掩護

- 誰：站在那一格（`cellOf(u.x), cellOf(u.z)` 那一格）的任何一方的單位，只要 `!UNIT_KINDS[k].armored && !UNIT_KINDS[k].carry`（步兵班、機槍組、狙擊手、反戰車小組、工兵、火焰噴射器、觀測員、迫擊砲、反戰車砲、榴彈砲、防空砲都算；坦克、裝甲車、卡車、半履帶車不算）。跟壕溝一樣不分敵我：佔了對方的沙包，照樣躲得住。
- 什麼時候：沙包 `hp > 0` 而且 `left = 0`（工地不擋子彈）。
- 多少：承傷取 `min(原本算出來的, 50)`——不疊乘（彈坑 75 加沙包＝50）。
- 哪些傷害：`damageUnit` 帶 `allowGroundCover` 的那些（穿甲、步槍、機槍、高爆濺射、炸彈）。**火焰**（R1002：`allowGroundCover = false`）、房子倒塌的 20、跳車的傷害照舊不打折。
- 壓制：`morale.ts` 的 `coverPct` 用同一支 `cover1007`，所以壓制照 `supPct(50)`＝七成（跟房子一樣）。`tests/morale.mjs` 那條「`coverPct` 跟實際扣的血一致」在沙包上也要成立。
- 潰退（`morale.ts` 第 97 行 `startRout`，不動；`morale2.mjs` 錨著）：
  - **第一版（`morale`＝1）：沙包留得住。** 第一版的條件是 `coverPct(w, u) < 100`——任何掩護都留得住（房子、樹籬、彈坑都是），沙包經過 `coverPct` 自動算進去。原稿只寫了第二版，審查補上。
  - **第二版（`morale`＝2）：沙包跟房子一樣留不住**（只有碉堡與壕溝留得住）。
- 同一發高爆先算人、再算沙包（`land()` 裡單位的濺射迴圈在前、3.5 那一行在後）：打散沙包的那一發，裡面的人照樣吃到這一發的掩護。

#### 3.5 怎麼打散

- **高爆**：`land()` 在鐵絲網那一段後面加一行：每一處 `hp > 0` 的沙包，格中心離落點 ≤ `R + HALF`（跟鐵絲網同一個判斷）→ `hp = max(0, hp − k.dmgBld)`。換算：榴彈砲 60（兩發近彈打散）、R140 的 M-30 72、M7 Priest 65、迫擊砲 12（十發）、俯衝轟炸一枚 160（一枚就散）。
- **工兵**：對方的工兵點它 → R1002 的爆破：走到挨著、倒數 120 步（受壓、釘住照 R052 變慢）、一包就打散（走鐵絲網那一條：`hp = 0`、出 `wire` 事件與小爆炸事件）。
- **不會打散**：穿甲彈、步槍、機槍、火焰、煙幕（`land()` 這些在高爆那一段之前就 return 了）。坦克在遊戲裡只打穿甲彈，所以直射打不壞沙包。
- 打散的（`hp = 0`）：沒有掩護；畫成地上一攤散掉的沙包；留在清單裡，等下一次有人堆的時候被重用（3.2）。
- 自己這一方拆不掉自己的沙包；壞了不能修（重堆＝再付 10）。

### 沒做成的事

1. **掩護不分方向。** 只看「人站在哪一格」，前後左右來的子彈都打一半；畫出來的馬蹄形開口在後面只是樣子。要分方向得讓 `damageUnit` 知道子彈從哪裡來（`land()` 有 `s.sx, s.sz`，高爆濺射沒有方向），而且要改的三行被守衛錨著；另開一張。
2. **站在沙包「後面」（隔壁格）不算。** 同上。
3. **不擋路、不擋車。** 1940 年的路障常有沙包，但擋車的路障要「車」「人」兩張通行表，是 R024b（龍牙）的事。
4. **裝甲車輛壓不平沙包。** 真實的坦克會輾過機槍陣地；但尋路不避開沙包，自己的坦克也會一路把自己的沙包壓平。要先讓車輛的路避開自己的沙包，另開一張。
5. **布陣時（第 0 步）不能堆。** 布陣版的沙包陣地（扣 8 點建材）留給 R024b。
6. **不能拆自己的、不能修。** 壞了重堆，再付 10。
7. **打散的那一攤不給半掩護**（彈坑有 75，散掉的沙包沒有）。
