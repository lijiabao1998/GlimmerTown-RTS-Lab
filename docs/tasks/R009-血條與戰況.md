## 為什麼做這張

現在玩家完全看不出單位還剩多少血：坦克被打了兩發跟沒被打長得一樣，要不要撤退、該先集火誰都只能猜。房子也一樣——還要幾發才塌，只看得出三段（完好／空殼／瓦礫）。對轟的決策需要這個資訊。

## 做什麼（畫面＋介面，不改模擬）

1. **單位血條**：單位頭上一條細血條，**受過傷或被選取**時才顯示（滿血又沒選的不畫，畫面乾淨）；顏色綠 → 黃 → 紅；扣血時白色殘影從舊血量慢慢縮到新血量（0.5 秒）。敵方單位只在看得到時顯示（R100）。
2. **建築耐久**：被選中的建築目標（點房子下砲擊指令時、或我方單位正在打的那棟）頭上顯示一條耐久條，標出「空殼」那一格門檻（70%）。
3. **選取資訊**：提示列加上選取單位的平均血量與正在做什麼（移動／攻擊／砲擊／待命）。
4. 血條是兩個實例化網格（底、填色），只有要畫的時候才有實例；開局滿血沒選取＝ 0 個實例、不加繪製呼叫。
5. **逃生閥** `?noR009=1`：全部不畫，回到 R008 的樣子；雜湊不變。
