# R109［待辦 9］框選與長按砲擊：保留原手勢的快捷操作
<!-- card: sim=no; golden=無; valve=?noR109; owner_ok= -->

## 為什麼做
多台車要逐個點選，手機對指定地點切彈種也要來回按工具列。用新增快捷手勢縮短操作，但保留玩家已熟悉的拖曳平移、捏合與點按；不把原本拖曳改成另一套操作。

## 做什麼
- 桌機新增 Shift＋滑鼠左鍵拖曳框選，把框內存活我方單位加到目前選取；一般拖曳仍平移，Shift 點按仍切換單位選取。
- 手機單指在地圖靜止長按 500 ms，叫出該地點的一次性「高爆砲擊／煙幕／取消」選單；放手不發指令，再點選單才發一次既有 fireAt 指令。
- 沿用高爆的間接射擊單位與 R107 煙幕榴彈砲限制，其他混選單位不被改命令；不改工具列的彈種／砲擊模式狀態。
- 新 DOM 框與選單有 `?noR109=1` 逃生閥；加真實 CI Chrome 指標事件測試和隔離負控制，保留所有原操作守衛。

## 不改什麼
不改模擬、指令格式、golden、AI 或步兵專屬邏輯、武器數值、相機架構、全局畫風、後製、套件、預算或受保護工具。不是把普通左鍵拖曳換成框選；布陣、原點按／右鍵／滾輪／雙指／雙擊都保留。Claude 的 R011／R012 卡已把此項留給 GPT；本卡不做反砲兵或防禦工事。

## 驗收（動手前寫）
1. 只有戰鬥中的滑鼠主鍵＋Shift 才進框選，位移大於 8 CSS px 啟用；四種拖曳方向與矩形邊界結果一致。沿用單位畫面位置／屋頂高度，只加入存活我方，不選敵人或死者；既有選取保留、空框不清掉。框選不寫指令、不平移、不觸發慣性；小於等於 8 px 保持原 click／Shift-click。
2. 單一 touch 靜止位移不超過 8 px，499 ms 不開、500 ms 開一次選單；開啟和原手指放開不發任何指令、不補一次 tap。位移大於 8 px 取消並走原平移；第二指取消長按並保留 pinch，兩指放開不能補 tap。布陣時不啟用框選或長按。
3. 選單保存觸發時有效的目標格；高爆只向目前存活我方間接射擊單位發一條 fireAt，煙幕只向目前存活我方榴彈砲發一條 ammo:smoke 的 fireAt，點選當刻重新驗資格。混選其他單位不動；敵人／房屋位置也走指定地點砲擊，不誤走 attack 或進駐。開啟、取消、地圖外點擊關閉、無合法目標／單位皆不發指令；不改原工具列模式，不能做時顯示原因。
4. pointercancel、仍活躍時 lostpointercapture、第二指、Escape、重新開始／重播、開說明／戰報、離開戰鬥、視窗失焦／尺寸改變都清掉必要暫態與計時，不能晚到發命令；正常長按放手後選單仍可點。舊單／雙擊、右鍵、滾輪、平移慣性、捏合、小地圖及布陣操作結果保留。
5. `?noR109=1` 恢復本卡前的輸入與畫面，不顯示框／選單。同樣種子和指令紀錄的世界／RNG／hash 不變，不修改任何 src/sim 或 golden；原 SCRIPT 600／1200 tick 仍 c789deeb／f3364bb6，JSON 重播與 clone 保持一致。
6. 412×860 的選單每個按鈕至少 44×44 CSS px、整體留在視窗內，避開工具列、標題、小地圖、生產列；真實 DOM 邊界／hit test 驗證，不只用 CSS 算式。新增框與選單是 DOM，不增 WebGL calls；手機開局不超 20 calls／80,000 triangles，戰鬥不超 22／80,000；查看最新 CI 四圖和新手勢特寫。
7. 新增的 tests/*.mjs 在 CI 用真實 Chrome CDP 滑鼠／觸控事件覆蓋框選、長按、放手不下令、兩種砲擊、取消、雙指與逃生閥；精確時間／位移邊界用純控制器假時鐘避免瀏覽器排程誤差。測試自行建到獨立暫存目錄，唯讀重用 tools/cdp.mjs，不改受保護工具／工作流；每支沿用 unit 的 120 秒上限，實測不夠就拆支，不放寬上限。
8. 每組新守衛有隔離 production-source 弄壞的對應紅燈；瀏覽器負控制只在暫存 bundle，不能把測試開關放進出貨程式。既有斷言／門檻不削弱，必要的舊 mock 新狀態支援要記明。獨立審查決定性、舊操作相容與驗收。
9. 本機 typecheck、完整 unit、build、smoke、main 版車道逐項據實記錄。若新瀏覽器守衛遇本機已知 socket 權限限制，明列未執行並非綠燈，不隱藏成 exit 0；CI 嚴格失敗，不略過。最新 CI smoke／gpt-lane、合後 main／Pages 全綠才完成；CI 模擬觸控不宣稱 Android 實機。
