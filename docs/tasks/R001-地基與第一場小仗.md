## 為什麼做這張

GPT 要在這個倉庫無限迭代，就需要一個能跑、能驗、會擋壞改動的地基：工具鏈、模擬與渲染分開、決定性守衛、CI 閘門、規則文件。只給空倉庫，第一波就會各寫各的，之後每一波都在補地基。

## 做什麼

1. 工具鏈：TypeScript 7.0.2＋three 0.186.1＋Vite 8.3.1＋vite-plugin-singlefile 2.3.3（版本釘死，與 3D-lab 相同），輸出單一 `dist/index.html`。
2. 模擬（`src/sim`）：固定 20 tick/秒；位置用整數（1 格＝256 單位）；亂數狀態存在世界裡；玩家輸入只有「指令」，全部記錄可重播；世界雜湊。
3. 一張程序生成的二戰村莊街區（32×32 格）：十字路口、房子、教堂；兩方各 3 輛坦克＋1 門榴彈砲。
4. 戰鬥最小循環：選取、移動（格子 A*）、坦克直射（被房子擋住就打在房子上）、榴彈砲間接射擊（散布；沒有友軍看得到目標時散布加倍）、建築三段損壞（完好→沒屋頂→瓦礫）、彈坑、勝負。
5. 渲染：固定正交斜視相機（不旋轉，光永遠從畫面左上來）、像素風 A 後製、單位與砲彈用實例化網格、爆炸與煙（有逃生閥 `?fx=off`）。
6. 守衛與 CI：Node 端守衛、無頭 Chrome 煙霧測試、GitHub Actions；main 綠燈後發布 Pages。
7. 規則文件：`CLAUDE.md`、`AGENTS.md`、`docs/R000-願景.md`、`docs/DECISIONS.md`、`docs/GPT-方向.md`、`docs/迭代不改壞標準.md`、`docs/DOTS.md`、`LOG.md`。

## 驗收（動手前寫）

1. `npm run typecheck`、`npm run unit`、`npm run build`、`npm run smoke` 在本機全綠；`.github/workflows/ci.yml` 在推送與 PR 上跑同樣四步。
2. 建置產物只有一個 `dist/index.html`；煙霧測試量到的網路請求全部是本機（零外部請求）；`src` 裡沒有圖片、字型、模型、音效檔。
3. 純度守衛：`src/sim` 不 import three 或 render、不碰 DOM、不用 `Math.random`／`Date`／`performance.now`，也不用浮點超越函式（`Math.sin/cos/tan/atan2/sqrt/hypot/pow/exp/log` 等）。掃描器自我測試：禁止片段全部抓到，註解與字串裡的同樣字眼不誤報。
4. 決定性：同種子＋同指令紀錄，跑 1200 tick（60 秒）兩次雜湊相同；換種子雜湊不同；從指令紀錄重播與直接跑的雜湊相同；**Node 與 Chrome 跑同一場腳本戰鬥，雜湊相同**。
5. 黃金雜湊：腳本戰鬥 1200 tick 後的雜湊釘在 `tools/golden.json`；改到模擬的卡必須在卡面寫明新舊雜湊與原因。
6. 模擬行為各有一條守衛：A* 繞過完好建築、穿過瓦礫；坦克瞄準建築後面的目標，砲彈打在建築上；損壞門檻（損壞 <0.3 完好、≥0.3 沒屋頂、≥1 瓦礫，瓦礫可通行、不擋射線）；榴彈砲拒絕最小射程內的目標；高爆彈留下彈坑；死掉的單位不再被瞄準；一方全滅時判勝負。每條守衛都故意弄壞一次，確認第一個紅燈落在它身上（紀錄寫在下面）。
7. 手機預算（412×860）：開局場景繪製呼叫 ≤ 20、三角形 ≤ 80,000（含陰影那一趟）；頁面零錯誤。
8. 觸控：用真的觸控事件，點自己的單位會選取、點地面會下移動指令（煙霧測試斷言指令真的進了紀錄）。
9. 樣張：桌機 1280×800 與手機 412×860，開局與腳本戰鬥 30 秒後各一張，當 CI 附件上傳（不進倉庫）。
10. 文件齊：第 7 項列的檔案都在，`docs/GPT-方向.md` 的開關是「運行」，方向欄逐字抄業主原話。
