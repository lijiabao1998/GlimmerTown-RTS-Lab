# R121：可布設、可破壞的鐵絲網

## 為什麼做
待辦16：讓布陣能選擇以低矮鐵絲網引導徒步單位繞行，或用砲火清除通道；坦克與牽引砲仍能通行。

## 做什麼
一段2×1、可旋轉、1建材的鐵絲網，沿用建築耐久與砲擊，共享8點布陣預算。徒步單位不能穿過完整鐵絲網；車輛能過。鐵絲網不擋視線／射線、不給房屋駐守掩護。只補障礙的必要程序外形與建造選項，不做全局美術。

## 不改什麼
不改敵方AI、兵種／單位數值、保護工具、規則、套件、光／鏡頭／畫風；不做Claude的龍牙與沙包；不重編R114。

## 驗收（動手前寫）
1. 玩家可用既有布陣指令放置及旋轉鐵絲網，成本與建築／戰壕合計不超8；非法位置或封死徒步通路時拒絕且世界不變。
2. 完整鐵絲網使觀測員、步兵、徒步迫擊砲尋路繞行，所有既有車輛可以穿越。移動、攻擊追蹤、對地指令與新生產單位均使用一致通行規則，不能藉駐守參數穿過鐵絲網。
3. 沿用砲擊傷害將鐵絲網打成殘骸後徒步單位也能通過；鐵絲網不提供房屋掩護，不遮擋射線／視野；既有房屋行為保持。
4. 新紀錄JSON重播、中途structuredClone續跑及同種子同指令雜湊一致；既有黃金腳本以unit實測為準，不修改既有紀錄格式。
5. 手機可選取／旋轉／放置，按鈕不互相遮住；程序模型完整／損傷／殘骸可辨，固定tick有特寫。noR121隱藏新建造選項、降低鐵絲外形細節，但同一既有紀錄的模擬雜湊不變。
6. 新守衛有故意破壞的負控；typecheck、unit、build、smoke及main版gpt-lane驗證。無法在本機執行的檢查照實記錄，需CI補驗，不冒稱通過。
