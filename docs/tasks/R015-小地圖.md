## 為什麼做這張

手機上一次只看得到戰場的一小塊：敵人從哪邊來、自己的車散在哪、榴彈砲在打哪一區，都要拖來拖去才知道。RTS 的小地圖是最基本的全局資訊，也是手機上最快的移動鏡頭方式。

## 做什麼（只改介面）

1. **小地圖**：畫面右上（按鈕列下面）一張菱形小地圖，方向跟主畫面一樣（斜 45°、上下壓扁一半），用 DOM 的 2D 畫布畫（不加 WebGL 繪製呼叫）：地形（路、草、田）、還站著的建築、瓦礫、彈坑、我方單位藍點、**看得到的**敵方單位紅點（R100）、目前畫面看得到的範圍（白框）。
2. **點小地圖**：鏡頭滑到那一點（有 R012 就 0.4 秒平滑，`?noR012=1` 時直接跳過去）。
3. 布陣時也在；手機 412×860 不擋按鈕、不擋布陣列與提示列。
4. 純邏輯（地圖格 ↔ 小地圖座標、要畫哪些點）放在 `src/ui/minimap.ts` 的純函式，Node 可以測。
