# R019 生產與補給：指揮部、出兵、打掉指揮部才算贏

**狀態**：完成
**基線**：`3d47241`（main，R017 合併後；R018 合併後把 main 合進來）
**授權**（業主原話，2026-10-18）：「和 AI 對戰（電腦對手會建城、出兵、進攻）」；北極星「打開會玩一整天的二戰遊戲」。路線圖階段 A 的 R019＋R020 合成這一張（只做一半的話勝負規則會不一致）。

## 為什麼做這張

現在一局兩分鐘就結束：雙方各五台，打完就沒了。北極星的評量標準「一局可以打 15–30 分鐘」需要補給與出兵；「電腦會出兵、進攻」也需要同一套規則。

## 做什麼（模擬＋介面＋畫面）

1. **新指令 `eco`**（只加不改，只在第 0 步有效）：雙方在自己的出生角落各放一座**指揮部**（2×2、很硬；位置用固定規則從角落往外找空地，不壓單位、不上路、不堵死通路），開始累積補給。
2. **補給與生產**：每秒 +1 補給（開局 60）；新指令 `produce {side, kind}` 花補給排進指揮部的生產佇列（最多 5 個）：坦克 40／15 秒、榴彈砲 50／20 秒、觀測員 15／6 秒；做好在指揮部旁的空格出生，走到往地圖中央 4 格的集結點。每方同時活著最多 16 台。
3. **勝負**（有指揮部時）：一方的指揮部被打成瓦礫就輸（同一步兩座都塌＝同歸於盡）；全軍覆沒但指揮部還在，不算輸（可以再出兵）。沒有 `eco` 的局照舊「全滅才輸」。
4. **電腦**（R018）：有補給就出兵（按難度的比例：坦克為主、保持一個觀測員、榴彈砲最多兩門）；目標改成對方的指揮部；坦克整組以最前面那台為準往前推（後來出生的會追上）；看不到敵方單位、指揮部在射程內時轟指揮部。
5. **畫面**：指揮部模型（沙包圍牆、指揮所小屋、天線、旗桿，旗子只用陣營色、不畫任何徽記）。**介面**：開戰後下方一列「坦克 40／榴彈砲 50／觀測員 15」與補給、佇列；按鈕 ≥ 44 像素。
6. **逃生閥** `?noR019=1`：不送 `eco`，回到 R018 的打法；雜湊不變。
7. 守衛 `tests/eco.mjs`；README、LOG。

## 不改什麼

- 不改既有單位數值、地圖生成、腳本戰鬥；黃金雜湊不變（`98dc0f18`）；沒有 `eco` 的舊紀錄雜湊不變。

2. `tests/eco.mjs`：

## 施工紀錄

1. `5dce521` 先推卡面（驗收條件寫在動手之前，之後沒改）。
2. `src/sim/eco.ts`（新）：`startEco`（`eco` 指令，第 0 步）——從各自的角落往外找第一個放得下 2×2 指揮部的地方（不上路、不疊、隔一格、不壓單位、不堵死通路），`builtBy` 標陣營，送 `build` 事件（R016 的升起與 R004 的揚塵自動接上）；`produce`；`ecoStep`——每 20 步 +1 補給、佇列進度、做好就在指揮部旁一圈的空格（離地圖中央最近、沒有車停著）出生，自動走向往中央 4 格的集結點；每方活著滿 16 台就先等著。
3. `UNIT_KINDS` 加 `cost`、`buildTicks`（坦克 40／300、榴彈砲 50／400、觀測員 15／120）；`BK_HQ`（1200 血；第一版 600 血三輛坦克 24 秒就拆完，調高）。世界的 `eco` 只在有時才折進雜湊。
4. `step()`：玩家指令之後先 `ecoStep`、再讓電腦想（剛出生的這一步就能被指揮）；`checkWinner` 有指揮部時改成「指揮部塌了才輸」。
5. 電腦（R018）：有補給就出兵（缺觀測員先補、榴彈砲普通以上最多兩門、其餘出坦克，佇列最多兩個）；看不到敵方單位時目標＝對方指揮部；坦克以最前面那台為準推進（**只在有補給時**——第一版把它也套到沒有補給的局，R018 的難度測試少贏一局，改成只在有 `eco` 時用）；指揮部進射程就轟它；榴彈砲同樣轟指揮部。
6. 畫面：指揮部模型（一圈沙包、東邊留口、指揮所小屋、天線、旗桿；旗子只用陣營色：我方藍、入侵方灰，不畫徽記）。`MAX_UNITS` 64 → 512（出兵後 id 會一直長）。介面：生產列（坦克 40／榴彈砲 50／觀測員 15、補給、佇列縮寫、進度條；沒變就不碰 DOM）；開戰時送 `eco`（`?noR006=1` 流程在開頁）；`__rts.eco()`。README 逃生閥表與試玩清單第 7 項。
7. `tests/eco.mjs`（5 條）；煙霧測試加手機真觸控出兵與 `?noR019=1`（指令在下一步才套用，守衛按完先走一步再讀）。
8. 合進 R018（壓扁合併）時六個檔同內容衝突，取 R019 這一邊；合併後的樹跟合併前相同。

1. **沒有補給點可以搶**：補給只按時間進帳；路線圖上「佔領補給點加速」沒做。

4. 電腦的兵種比例很單純，沒有依對手的組成調整；不會蓋布陣以外的建築。
