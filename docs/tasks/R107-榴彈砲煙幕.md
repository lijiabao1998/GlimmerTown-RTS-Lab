# R107［待辦 7］榴彈砲煙幕：為轉移陣地遮住視線
<!-- card: sim=yes; golden=d22b1d45→f3364bb6; valve=?noR107; owner_ok= -->

## 為什麼做
榴彈砲除了打爛掩體，也能暫時切斷觀測，為坦克繞行或換位創造空檔。煙幕仍擋不住盲射與實體炮彈，形成火力與遮蔽的選擇。

## 做什麼
- 沿用既有砲擊操作，加高爆／煙幕彈種切換；煙幕只由榴彈砲接受，使用原射程、裝填與有限四發任務。
- 煙幕彈無傷害、無彈坑；落地留下半徑 2 格、20 秒的煙團，固定種子選出的整局風向每 tick 漂移 1 個位置單位，最多 8 團，滿額汰除最舊。
- 煙幕只影響共用視線，不改實體建築阻擋、通路、移動速度或敵方 AI 策略；所有持續狀態進入決定性世界與雜湊。
- 必要的灰白煙團表示沿用現有網格／效果池；由世界重建，不依賴曾經看見落點。`?noR107=1` 只關新增煙團畫面，重播與模擬相同。
- 保留原腳本全部指令，於晚段加煙幕情境，讓原 CI 的 Node／Chrome、30 秒樣張與預算可實際包含煙幕；另外固定舊腳本驗相容。

## 不改什麼
不改 AI／步兵專屬邏輯、單位數值、裝甲面向、R024b 障礙物、相機／光／後製／全局畫風，不做長按或框選，不增加網格呼叫預算、套件或受保護檔案。這是一張煙幕玩法卡，畫面只提供必要辨識，不夾帶美術重做。

## 驗收（動手前寫）
1. 可選煙幕的 fireAt 指令只讓所屬且存活的榴彈砲執行；混選不誤發、缺省仍高爆；沿用原射程與裝填，停下才射。煙幕四發後即停止，對建築也不無限射；move／attack／stop／普通 fireAt 能結束煙幕任務。
2. 煙幕落地不扣血、不傷房屋、不挖坑、不累積高爆試射修正；既有高爆、直射、建築阻擋、路徑與彈坑掩護不變。煙幕不攔截實體炮彈。
3. 煙團半徑 2 格、壽命 400 tick、最多 8 團，首次有效落地決定固定種子的風向並保存；位置整數、每 tick 漂移、準時消散、邊界與滿額汰除決定性。查視線與渲染不抽模擬亂數。
4. 雙方共用視線對稱；穿煙、起點或終點在煙內不可直接看穿，其他友軍繞側可重新觀測，漂移與消散即時恢復舊位置視線。保留最後座標盲射，不改 AI 專屬策略，不洩漏煙內敵軍。
5. 原七條腳本獨立 fixture 的 600／1200 tick hash 保持 14108ab2／d22b1d45；舊世界缺煙幕欄位可接續。新煙幕指令 JSON、同種子重跑、途中 clone 接續一致；新增持續狀態皆進 hash。黃金只按實際完整 unit 輸出更新，Node／Chrome 必須一致。
6. 新 SCRIPT 到 600 tick 確有存活煙幕；新建 BattleView 與逐 tick 更新都能畫出，暫停時不漂移，開關及畫面更新頻率不改世界。煙幕不是火花／爆炸，既有逃生閥仍可用；必要煙團不被爆炸粒子完全擠掉。
7. 彈種選擇沿用既有砲擊流程，412×860 按鈕至少 44×44、不蓋住原操作；手機開局不超 20 calls／80,000 triangles，煙幕及戰鬥特寫不超 22／80,000。查看 CI 桌機／手機四圖及煙幕數字；真實新增按鈕觸控若無法跑，明列缺測，不冒充通過。
8. 新守衛逐組故意弄壞並確認對應紅燈，既有守衛與門檻不削弱。typecheck、unit、build、smoke、main 版 gpt-lane 逐項記錄；本機 Chrome 受限時據實靠 CI，最新提交 smoke／車道全綠、main／Pages 綠才完成。
