## 為什麼做這張

現在敵人只會站在原地自動還擊：玩家什麼都不做就永遠不會輸，一局沒有張力。北極星的第一個評量標準就是「電腦對手會主動進攻」。

## 做什麼（模擬＋一點介面）

1. **新指令 `ai`**（只加不改）：`{ t: 'ai', side, level }`——讓電腦接手那一方（level 1 簡單、2 普通、3 困難）。開戰時跟布陣一起寫進第 0 步的紀錄，所以重播自動一致；腳本戰鬥沒有這條指令，黃金雜湊不變。
2. **電腦在 `step()` 裡想**（`src/sim/ai.ts`，純整數、決定性、不碰 `World.rng`）：每隔一段時間（困難 1 秒、普通 1.5 秒、簡單 3 秒）看一次世界，**只用自己這一方看得到的敵人**（不偷看迷霧）：
   - 坦克：看得到敵人 → 集火（普通以上全組打同一個，先打快死的；簡單各打各的最近）；看不到 → 整組朝目標推進，每次往前約 6 格，挑**旁邊有房子當掩體**的空格；受重傷（普通以上）往回撤。
   - 榴彈砲：打看得到、在射程內的敵人。
   - 觀測員（普通以上）：進駐前線附近的房子當眼睛。
   - 目標：一開始是對方的出生角落；看到過敵人就改朝最後看到的位置。
3. 電腦的記憶（最後看到敵人的位置、下一次想的時間）放在世界裡、只在有電腦時折進雜湊（沒有電腦的世界雜湊不變）。
4. **介面**：開戰時（布陣流程與 `?noR006=1` 流程都是）送出 `ai` 指令；網址 `?ai=1|2|3` 選難度（預設 2）。**逃生閥** `?noR018=1`：不送，敵人回到原地還擊。
5. 守衛 `tests/ai.mjs`；README 試玩清單與逃生閥表、LOG。

## 不改什麼

- 不改既有單位數值、勝負條件、指令格式（只加 `ai`）；腳本戰鬥與黃金雜湊不變（`98dc0f18`）。
- 不偷看：電腦不讀自己看不到的敵人位置（出生角落是開局就知道的地圖情報）。

## 驗收（動手前寫）

1. `npm run check` 本機與 CI 全綠；黃金雜湊仍是 `98dc0f18`；沒有 `ai` 指令的舊紀錄雜湊不變；Node＝Chrome。
2. `tests/ai.mjs`：
   - 種子 1944，敵方普通難度、玩家什麼指令都不下：60 秒內敵方坦克的重心離我方出生角落明顯變近（至少近 6 格），而且敵方有開火；**玩家輸**（敵方勝）在 10 分鐘（12,000 步）內出現。
   - 不偷看：電腦每一次下的攻擊指令，目標在那一刻都是電腦那一方看得到的（掃整場）。
   - 集火（普通）：同一次想的時候，有兩輛以上坦克在打時，它們打同一個目標。
   - 決定性：含 `ai` 指令的紀錄跑兩次相同、JSON 來回相同、中途深拷貝接著跑相同；電腦不動 `World.rng` 以外的東西以外的亂數（不抽 `World.rng`）。
   - 難度有差：困難比簡單更快打完玩家（或簡單在同樣時間內贏不了）。
3. 煙霧測試：預設開頁（布陣）按開戰後紀錄裡有 `ai` 指令；跑 30 秒敵方有單位離開出生角落；瀏覽器雜湊＝Node 重播；`?noR018=1` 時紀錄裡沒有 `ai` 指令。既有的觸控、重播測試照舊通過。
4. 每條新守衛故意弄壞一次，第一個紅燈落在它身上（記在卡面）。
