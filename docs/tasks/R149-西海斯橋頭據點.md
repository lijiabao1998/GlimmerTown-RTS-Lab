# R149 西海斯橋頭據點

## 為什麼做

R090 的海斯對局集中在中央橋。選西海斯橋（地圖 5 的第二座橋），讓玩家把一支部隊派往側翼，就有換取少量補給的機會。

## 做什麼

雙方用相同的部隊到場、駐守、奪回規則。小地圖指明橋的位置與現況。用原有的單人對手實測它是否願意來爭，再決定單人預設。

## 不改什麼

沿用現有勝負條件、地圖、電腦決策與補給基準。開局紀錄決定規則，舊局保留當時的行為。

## 驗收（動手前寫）

1. 只在海斯指定的一座側橋設點。雙方各自單獨進圈駐守五秒後能佔領，也能奪回。雙方同在時進度與發款暫停，空點不發款。陣亡、乘車與被拖行的單位不額外計入。斷橋停止服務，修好可用。
2. 完整駐守十秒發一點補給，首佔本身不發獎金。跑一場先佔方最後仍輸掉的對局，用指揮部勝負驗證。
3. 兩個真正連線的瀏覽器，各用自己那一方的指令從正常出生點到橋頭。兩端都看得到控制、爭奪、易手，核對同步雜湊與指令重播。桌面與手機尺寸讀得到提示。
4. 用正常單人電腦與玩家駐守命令，普通、困難各至少六個種子。分別記玩家抵達、電腦進圈、實際爭奪與易手。若無穩定爭奪，就只在雙人對戰預設開放。
5. 中途存讀、舊指令、其他地圖、關閥、新局及兩端不同本機設定有對照。新守衛做負對照；保留原黃金雜湊。合併以最新提交完整 CI 為準。

## 施工紀錄

基線 `73ef735`。選用既有地圖的西海斯橋，格座標（42，86）。
