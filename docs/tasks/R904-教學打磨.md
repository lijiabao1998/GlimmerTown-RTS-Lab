**狀態**：施工中
**基線**：`origin/main` @ `6f61d00`（R902 已合入，黃金雜湊 `eea1d59b`）

## 為什麼做這張

R902 的教學會自己按時間換課，教學開著時敵方仍會打，412 寬直向的面板還會擠到「沙盒模式」，計時容易換行，「新手教學」按鈕掉在說明框下緣外面。

## 做什麼

1. 教學模式開著時，敵方不攻擊。旗標在 `src/sim/`（世界欄位，由指令寫入），`src/sim/ai.ts` 不改。旗標沒立起來時，一般對戰與 1200 tick 黃金雜湊仍是 `eea1d59b`。
2. 時間走完不自動換課。做完該課目標，或按「下一步」，才進下一課。移動、採集、建造、攻擊四課都測這兩條路。
3. 412 寬直向：教學面板不蓋住「沙盒模式」，仍避開具／產／框與安全區。計時（例如 `0:03／3:00`）不換行；說明文字太長就縮短。
4. 「新手教學」放在說明框裡面，不掉到框的下緣外面。

## 不改什麼

- 不改 `src/sim/ai.ts`、`src/render/post.ts`、`tools/`、`SCRIPT`、黃金雜湊。
- 不搬既有檔案，不加 npm 套件，不加外部素材。
- 不調高每幀繪製 20 次、三角形 80,000 的預算。
- 不改 R902 卡的驗收原文。`?noR902=1` 仍不掛教學、不寫紀錄。

## 驗收（動手前寫）

1. `npx tsc --noEmit` 過。`tests/tutorial.mjs` 過，而且 `hashWorld(runScript())` 仍是 `eea1d59b`。`SCRIPT` 的 tick 序列不變。
2. 教學旗標沒設時，敵方攻擊指令與開火跟現在一樣。旗標設上之後，敵方的攻擊／砲擊指令不生效，敵方單位也不開火；我方攻擊仍生效。關掉旗標後敵方又能下攻擊。一般對戰不送這條指令時，世界雜湊與沒有這個欄位相同。
3. 什麼都不做，時鐘可以走到 3600，課仍停在移動。做完移動、採集、建造、攻擊的目標會各自進到下一課（最後一課做完是第 4 步），不必等時間。每一課按「下一步」也會前進，而且不算做完該課。跳過仍不算走完，時鐘停住。
4. 412×860 直向、教學開著：面板與「沙盒模式」、具、產、框的間距至少 16px（安全區內距算進位置），這幾顆按鈕的觸控打在自己身上。計時文字只有一行，形如 `0:00／3:00`。繪製 ≤ 20、三角形 ≤ 80,000。
5. 說明打開時，「新手教學」落在說明框矩形裡面，不在框的下緣之外。既有說明正文的句子順序還在。
6. 新行為至少弄壞一次，第一個紅燈落在這張卡的斷言上，記在下面。
