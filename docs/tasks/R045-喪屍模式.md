## 為什麼做這張

業主點名要的新模式。一般對戰是兩軍對轟；喪屍模式換一種壓力：

- 敵人數量多、一直來、越來越多；
- 不會開砲，只會往前撲；
- 玩家要用布陣（房子、圍牆、鐵絲網、戰壕）把他們擋在外面，再用坦克、步兵、榴彈砲把成群的喪屍打散。

這個模式能把既有的系統都用上：布陣、生產、砲擊、掩體、破壞。

## 做什麼

1. **新指令 `{ t: 'zombies' }`**（只加不改，只在第 0 步有效；第 0 步的 `map` 之後套）：
   - 世界多一個欄位 `w.zombies`（版本、目前波次、下一波的步數、已冒出、已擊倒、我方損失），有值才折進雜湊。
   - 敵方起手單位全部移除；我方單位不動、id 不變。
   - `eco` 只放我方指揮部、只給我方補給；敵方不布陣、沒有指揮部、沒有補給；`ai` 指令對敵方無效（喪屍有自己的規則）。
2. **喪屍**（新單位種類 `UK_ZOMBIE`，id 11，不能生產）：
   - 一群六隻，畫成六個人，像步兵班那樣一隻一隻倒下（每 10 血一隻）。
   - 走得比步兵慢；近身（1 格內）才攻擊，打人與打房子都痛，對裝甲只能抓幾下。
   - 攻擊是新砲彈種類「近身」：沒有曳光、不飛行、當步結算。
   - 不作弊：朝最近的「我方看得到它、它也看得到」的我方單位撲；看不到就朝我方指揮部走（建築本來就看得到）；沒有指揮部就朝我方出生角落走。
   - 會被房子、圍牆擋（繞路；走不通就打擋路的那一面）；鐵絲網照徒步規則擋。
3. **波次**（每秒 20 步）：
   - 第 k 波（k ≥ 1）在第 k×900 步冒出 4＋2k 群；上一波全滅就把下一波提早到 200 步（10 秒）之後。
   - 冒出的位置在地圖邊緣、離我方指揮部（沒有就是我方出生角落）至少 n/2 格，只用 `World.rng`。
   - 同時活著的喪屍群上限 48；冒不出來的排到下一步。
4. **勝負**：
   - 我方指揮部被拆掉（沒有指揮部：我方單位全滅）就結束，`winner` 是敵方；喪屍模式沒有「贏」，敵方沒有單位不算我方贏。
   - 戰報寫撐到第幾波、擊倒多少隻、損失多少；最佳紀錄存本機（`gtrts.v1.zombies.best`，讀不到不報錯）。
5. **入口**：
   - 布陣時左上多一顆「喪屍」鍵（跟 R043 的「地圖」鍵同一排），按下去回到喪屍模式的布陣第 0 步；再按回一般對戰。
   - 網址 `?mode=zombies` 直接開；`?noR045=1` 沒有入口、不認網址。
   - 大地圖也能開喪屍模式（`?map=64&mode=zombies`）。
6. **畫面**：
   - 喪屍用步兵的小人網格，不加繪製呼叫；
   - 灰綠膚色、破舊暗色衣服，走路前傾、搖晃；
   - 倒下的留在地上（沿用 R021），數量有上限，最舊的先淡掉，守住手機預算。
   - 開戰命令條（R041）寫「喪屍從地圖邊緣湧來。守住指揮部，撐越多波越好。」
7. **紅線**：喪屍沒有任何陣營徽記、軍服番號或納粹符號；不畫血腥特寫。
8. **說明面板**加一段喪屍模式；README 逃生閥表加 `?noR045=1`、試玩清單加一條。
