## 對目標的讀法（Claude 的讀法，不是業主的話；業主一句話就改）

- **「效能和美术你来决定」**：效能 2026-11-13 已經交給 Claude（R072）；這次加上美術——畫風、後製、整體調色盤、光的方向、房屋與單位的模型、夜戰與天候這些「整張畫面的觀感」，改由 Claude 決定，不再先拍對照圖等業主。照舊拍對照圖放進卡面，讓業主看得到改了什麼。
- **「以现有素材基础」**：在現有的程式、模型、地圖上長，不重寫、不換引擎；舊的重播與存檔照舊逐位不變（新東西放在新旗標後面）。
- **「二战完整装备」「更多二战真实武器装备」**：每種裝備的數字從真實的來，為了好玩才改，改了寫在卡面（跟現在一樣）。
- **「细化房屋美术水平，增加更多房屋」「更大战场」「更大规模 小兵班」**：房屋的細節與種類、更大的地圖、每班看得到更多人、場上更多班。這三件都吃效能：每張卡量手機與桌機的繪製呼叫、三角形與每步時間，預算要調就在那張卡寫調之前、調之後的數字（R072 的做法）。
- **「要求包含在线联机功能」**：一定要做。這個模擬是決定性的、只靠指令推進，最適合「鎖步」（每個人只送指令，各自跑同一個模擬）。分兩步：先兩個人一起打電腦（合作），再兩個人對打（對戰）。**真的放上網**要一台大家連得到的主機：伺服器程式會放在倉庫裡、零依賴、一個檔案就跑得起來，但放在哪台主機（費用、帳號、網域）是業主的事，做到那裡再問。
- **「红警是个参考，更现代化的红警，带建筑物破坏」**：參考的是這一類遊戲的玩法——蓋基地、生產、科技解鎖、資源、大規模對戰——不照抄任何一款遊戲的名字、單位、畫面或關卡；裝備照舊是真實的二戰裝備。「建築物破坏」：現在房子會打成空殼、瓦礫，往下做牆上打穿洞、塌一半、倒塌的過程。
- **「更好玩的参考也都能加」**：以二戰題材的即時戰略、戰術遊戲常見的玩法為參考（掩體、壓制、載具乘員、佔領據點），一樣不照抄。
- **「你来决定合并 和PR」**：跟 2026-11-13 一樣，CI 綠就自己合。
