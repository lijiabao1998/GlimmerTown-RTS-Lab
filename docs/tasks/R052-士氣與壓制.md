## 為什麼做這張

現在的步兵與砲組只有血量：子彈打到扣血，沒打死就照常開火、照常前進。真實的戰場上，火力的主要作用不是打死人，是讓人抬不起頭——被機槍掃到的班會趴下，被砲擊的陣地在砲擊期間幾乎不還擊，進攻的一方要趁砲火剛停、對方還沒回神的那幾秒衝上去。少了這一層，「先壓制再突擊」「砲兵準備」「誰先開火誰佔上風」這些二戰最基本的戰術在遊戲裡都沒有意義。

## 做什麼

### 1. 規則（只加不改；`rules` 指令多一個欄位）

```ts
{ t: 'rules'; force?: number; income?: number; ap?: number; morale?: number }   // morale＝1：士氣與壓制
```

- `morale` 是 1 才生效，存在 `World.rules.morale`，只在有值時折進雜湊。沒給＝現在的規則，逐位不變。
- **誰會被壓制**：沒有裝甲的單位——步兵班、觀測員、反戰車砲、迫擊砲、榴彈砲（砲組）。有裝甲的車輛與喪屍不受影響。
- 每個會被壓制的單位多一個**壓制值**（0–100，`Unit.sup`；是 0 時不留欄位，所以沒被打過的世界雜湊不變）。

**壓制值怎麼漲**（先乘「掩體」的百分比，再加上去；最多 100）：

| 來源 | 加多少 |
|---|---|
| 步槍齊射打在這個單位身上 | 25 |
| 直射砲彈打在這個單位身上 | 30 |
| 直射火力打在一棟房子或碉堡上 | 裡面進駐的每個單位照上面兩列的數字（再乘房子的掩體百分比） |
| 高爆彈落在附近 | 中心 `35 + 那門砲對單位的傷害 ÷ 2`（榴彈砲 70、迫擊砲 50），照距離線性遞減到 0；**壓制半徑＝殺傷半徑的兩倍** |
| 3 格內有友軍被打死 | 15 |

**掩體**擋壓制的效果只有擋傷害的六成（人躲在壕溝裡不容易死，但照樣抬不起頭）：`吃到的壓制 % = 100 − (100 − 吃到的傷害 %) × 3 ÷ 5`。

| 掩體 | 吃到的傷害（現有規則） | 吃到的壓制 |
|---|---|---|
| 空地 | 100% | 100% |
| 交通壕 | 90% | 94% |
| 彈坑、一般戰壕 | 75% | 85% |
| 樹籬林地、加固戰壕、房子裡 | 50% | 70% |
| 碉堡裡 | 25% | 55% |

- **指揮部穩住士氣**：離自己還在的指揮部 6 格以內，上面算出來的數字再乘 3/4。
- **怎麼退**：每 4 步 −1（從 100 退到 0 要 20 秒），在哪裡都一樣。

**三個狀態**

| 狀態 | 壓制值 | 效果 |
|---|---|---|
| 受壓 | ≥ 30 | 裝填慢一倍（射速剩一半）；移動速度剩一半 |
| 釘住 | ≥ 60 | 不能移動（趴下）；裝填慢四倍（射速剩四分之一） |
| 潰退 | ≥ 90 | 不能開火。步兵班、觀測員如果人在空地上（沒有任何掩體），會往自己那一側退 3 格，退的時候不聽指令；壓制值降到 60 以下才停下來、恢復聽指揮。人在掩體裡、或是砲組，就原地趴著 |

- （審查後寫明）砲本來就要停下來才能打：搬到一半被釘住的砲組趴在路上、砲沒架好，不開火；上表的射速適用於已經就位的單位。潰退的班退完一段如果還是潰退、人還在空地上，每秒會再看一次、再退一段。直射落在已經是瓦礫的房子上，不算打在房子上。
- 狀態一變就發一個事件 `{ e: 'morale', unit, state }`（給畫面用，不進雜湊）。
- 全部整數、不抽亂數；單位照編號順序處理。

### 2. 數字的相對關係與出處

| 關係 | 遊戲裡 | 出處 |
|---|---|---|
| 壓住人需要的火力遠少於打死人 | 壓制半徑是殺傷半徑的兩倍；榴彈砲落在殺傷半徑邊緣不扣血，但壓制值 +35（受壓） | Evans《British Artillery in World War II》：25 磅砲壓制一個目標每小時 8–32 發，「摧毀」要在 100×100 碼裡落 600 發（轉引自 balagan.info〈Artillery and Mortar Tactics of WW2〉） |

| 被壓住的人火力剩很少 | 受壓射速 1/2、釘住 1/4、潰退 0 | Rowland（英國國防作戰分析處；《The Stress of Battle》2006）：實戰中輕兵器只有靶場效能的 1/7–1/10（轉引自 Dupuy Institute） |
| 掩體保命的效果比「讓人敢抬頭」的效果大 | 掩體擋壓制只有擋傷害的六成；加固戰壕裡的單位要一個敵班打 5 輪（約 5 秒）才釘得住，兩個班同時打 2 輪 | Evans：趴著的傷亡風險是站著的 1/3，在散兵坑裡是 1/15–1/50（轉引自 balagan.info）；同一份資料說壓制這些陣地仍只要每小時 8–32 發 |
| 砲火不必打中也壓得住人 | 迫擊砲彈落在 1 格外（殺傷半徑邊緣，一滴血不掉）：每發 +25，3 秒一發，第 2 發受壓、第 5 發釘住。榴彈砲落在 1.5 格外（殺傷半徑邊緣）+35 受壓、不扣血；落在四分之一格外，沒被炸死的那個班（剩 2 點血）被釘住（+64）；正落在腳邊，空地上的班直接陣亡（傷害規則沒有變）。7 秒才一發 | 該文：蘇軍迫擊砲集火 2–3 分鐘約 50 發／2 英畝；Evans 的壓制與摧毀用彈量差距（同第一列） |

### 獨立審查之後改的

合併前請另一個只讀的審查者照卡面逐項找毛病。它沒有找到「規則沒開時會變」「不決定性」「雜湊或存檔漏東西」這一類的問題（另外拿基線跟這一版比了 54 局、每 50 步比一次雜湊，零差異），找到的是下面這些，合併前都處理了：

1. **搬到一半被釘住的砲組整段時間不開火。** 釘住的單位路徑還留著（壓制退了繼續走），而砲（榴彈砲、迫擊砲、反戰車砲）本來就是「還有路要走就不能打」。卡面只寫了「釘住射速剩四分之一」，沒寫這個情況。決定：**保留這個行為，寫成明白的規則**——搬到一半被釘住的砲組趴在路上、砲沒架好，所以不開火；原地被釘住的照四分之一打。上面「三個狀態」那張表適用於已經就位的單位。守衛補了兩種情況。
2. **選中的砲，裝填那一行的「剩餘」沒有算進變慢。** 改了：受壓乘 2、釘住與潰退乘 4，後面多一句「N 個被壓制（裝填變慢，潰退的不開火）」。（這是玩家目前唯一看得到的文字說明。）動的是 `src/ui/reloadStatus.ts`；為了讓它只匯入 `world.ts`（有兩支既有守衛把這個檔案改寫成 data: 模組來載入），三個門檻與狀態的定義搬到 `src/sim/world.ts`，`morale.ts` 轉出。
3. **潰退的班退完 3 格、火力沒停，就站在空地上一直不聽指揮也不再退。** 改成每 20 步看一次：還是潰退、人在空地上、沒有在退，就再退一段。
4. **在房子裡潰退、房子接著倒了，人站在瓦礫上卻不退。** 同一個修法（上一條的定時查看）涵蓋。
5. **直射落在已經是瓦礫的房子上，站在那塊地上的班照樣被壓**（而且照空地的量）。改成瓦礫上沒有「裡面」。
6. **守衛沒顧到的**：房子、彈坑、林地裡不退；觀測員會退；敵軍陣亡不算；打偏兩格不算；潰退中 `stop`、`attack`、`fireAt` 也不收；隔壁那棟房子裡的人不受影響；半路回神會停下來；退到一半的單位深拷貝與存檔後接著跑相同；設定頁閥關著時記憶不被洗掉、接回存檔時對齊。全部補上。原本喪屍那一局對照值只跑到第 1200 步、根本還沒打起來，換成第 3000 步（三波、兩百多次開火）；「沒開旗標沒有壓制狀態」從只看最後一步改成每一步都看。隔離副本故意弄壞 12 → 14 處。
7. **審查的觀察（不是程式錯）：潰退在實戰裡很少真的發生。** 它量了四局電腦對電腦共 14,500 步：28 次進入潰退狀態，只有 2 次真的往後退，那兩個班 14 步與 60 步之後就陣亡了。原因：空地上的步兵通常在累積到 90 之前就被打死；活到潰退的多半在房子裡（直射打房子不傷人、只壓人）、在彈坑裡（高爆彈在腳邊炸出彈坑，彈坑算掩體）、或是砲組，這三種都不退。沒有為了讓它常發生去改數字，記在「沒做成的事」。
8. **修正推上去之後 CI 紅了一輪**（最新提交 `ee80d0f` 的 43637078542）：`tests/reload-status-browser.mjs` 用文字比對 `reloadStatus.ts` 裡 `Math.ceil(u.cooldown * 10 / TICK_HZ)` 與最後那一行 `return`，第 2 條的改法把這兩段改掉了，它的故意弄壞找不到下刀的地方。本機當時只跑了選單相關的 Chrome 守衛，沒跑到這一支。改成不動那兩段的寫法（倍率乘在外面、附註併進 `remaining`），再推一次。

### 沒做成的事

- **電腦對手不懂這條規則。** 它不會先壓制再突擊，也不會把被釘住的單位撤下來。開著規則跟電腦打，電腦比較吃虧（留 R057）。
- **裝甲車輛完全不受影響。** 沒有關艙、乘員受驚、開頂車被壓制。
- **潰退很簡單，而且在實戰裡很少真的發生**：只往自己那一角一段一段退 3 格；不會找掩體、不會投降、不會整個班散掉，退的路上被打照樣挨打。審查量到四局電腦對電腦 14,500 步只有 2 次真的往後退（原因見上面第 7 條）。玩家比較常看到的是「受壓」「釘住」，以及躲在房子裡的班被壓到不敢開火。
- **彈坑算掩體**：高爆彈在腳邊炸出彈坑之後，那個班就算「在掩體裡」，潰退了也不退。合不合理沒有人實際玩過來判斷。
- **畫面上幾乎只有小方塊**：選中步兵時不會寫「受壓／釘住／潰退」；只有選中砲的時候，裝填那一行會寫「N 個被壓制」。說明面板（怎麼玩）沒有提，只有 README 寫了。沒有趴下的動作。
- **戰報沒有壓制的統計。**
- **數字都是遊戲設計**：門檻、每個來源加幾點、退的速度、掩體「六成」、指揮部的範圍與折扣、退幾格，沒有一個有出處。出處只支持「相對關係」，而且全部是二手轉引（balagan.info、Dupuy Institute、Isegoria），沒有讀到原書；Wavell Room 那篇（Swann 的數據）沒讀到，Wigram 1943 年的報告沒找到。
- **誰先開火誰佔上風的程度沒有調過**：空地上先開火的班第 3 輪就把對手釘住。只跑過幾局電腦對電腦，沒有人實際玩過、沒有在真手機上看過標記夠不夠明顯。
- **近身的喪屍不會讓人被壓制**（喪屍模式開著這條規則時，只有自己人的砲火與傷亡會）。
