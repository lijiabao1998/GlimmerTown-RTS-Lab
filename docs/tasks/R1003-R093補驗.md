## 施工紀錄

1. **對戰版的守衛第一版太弱。** 第 1 方偽造的「第 0 方俯衝轟炸」打隨機的格：第 0 方常常付不起 60 補給、目標格常常看不到，所以就算把鎖步的對戰過濾拿掉，偽造的命令也幾乎都被模擬自己的門擋掉——弄壞之後守衛照樣綠。改成：第 0 方不造兵（補給留著）、偽造的轟炸打第 0 方自己看得到的指揮部、另外偽造第 0 方生產它從來不造的輕坦克。改了之後拿掉過濾就紅在「偽造的命令沒生效」那一句。
2. **著色程式的守衛第一版也抓不到「換材質」。** 飛機的網格在開頁時就建好，著色程式那時就編了；把材質換成別種照樣是開頁時編，數量前後一樣——這正是 R093 的承諾（戰鬥中不臨時編譯）。要證明守衛抓得到，改用「飛機上天那一刻才換新材質」的弄壞法：13 → 14，紅在指定那一句。
3. **分出勝負時，空中鍵整列藏起來。** `air93.ts` 在同一個分支把選擇清掉（`armed = 0`），但藏起來的按鍵沒有更新字樣，還留著「轟炸」。玩家看不到也按不到，下一次顯示時就更新；照實記，不改程式（這張不改程式）。守衛驗「整列藏起來」。
4. **夾具**：`tools/r089-fixture.mjs` 加兩個量測掛勾：`programs()`（`renderer.info.programs` 的數量）、`hqDown(side)`（讓那一方的指揮部倒下）。只在測試的建置裡。
5. **順便補拍 R1002、R050 的截圖**（`tools/r050-shots.mjs` → `docs/shots/r050/`）：兵營、車廠、補給站、工地骨架、工兵、火焰噴射器正在噴。兩張 PR 都沒拍過畫面。
