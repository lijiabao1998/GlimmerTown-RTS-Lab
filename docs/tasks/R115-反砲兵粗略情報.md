# R115［待辦 11］反砲兵：小地圖上的疑似敵砲區

## 為什麼做

榴彈砲躲在視線外連續開火時，玩家目前缺少可用的反砲兵線索。把實際砲聲化成逐步收斂、會過期的粗略區域，讓玩家選擇盲射壓制或派觀測員確認，仍保留迷霧與精確偵察的價值。

二戰適配參考：[美軍《Field Artillery Journal》1944年1月，第39頁](https://tradocfcoeccafcoepfwprod.blob.core.usgovcloudapi.net/fires-bulletin-archive/1944/JAN_1944/JAN_1944_FULL_EDITION.pdf)記錄英軍聲測與閃光觀測用於敵砲定位。此卡僅取聲測概念；全32格戰場可收到線索、量化區域、三階收斂與30秒壽命均為玩法抽象，不宣稱重現歷史設備精度。

## 做什麼

- 真正開火的榴彈砲／迫擊砲才更新雙方對稱的區域情報，包含煙幕發射。保持原AI、射擊、移動與視線判斷。
- 每方最多保留8個敵方8×8格粗區的最近聲源。狀態只記粗區、2×2子區、次數與最後開火tick，不保存精確位置或單位ID。相同子區累積1–3級；換子區從1級重新開始，沒有新開火就不追蹤移動或死亡。600tick到期。
- 三級中心按8→4→2格量化；世界橢圓半軸為8×6、4×3、2×1.5格。橢圓始終包住來源量化格，第三級仍不提供精確位置。小地圖只使用當級公開投影，畫橙色虛線估計區，搭配簡短非精確提示；原小地圖點擊移鏡與既有盲射操作不變。
- 不增加WebGL網格；固定採樣點經原小地圖投影，裁於地圖菱形。`?noR115=1`只關新情報顯示與提示，不改模擬／hash。

## 不改什麼

不改敵方AI、步兵、R036裝甲、R024b障礙物、單位數值、指令格式、SCRIPT、spotted／LOS、敵軍模型／單位點選可見性、相機或操作方式、help文案／布局、全局畫風／後製／光源、預算或套件。R018的敵砲換陣地由Claude在本機制合入後另做。本卡只提供必要的小地圖情報辨識，不夾帶美術改版；不是防DevTools作弊工程。

## 驗收（動手前寫）

1. 只有正式fire事件中的間接射擊兵器實際開火才產生情報；裝填中、移動中不能射、無效／過近／過遠目標、直射與步兵不誤報。高爆與煙幕一致，死亡當步已發出的砲聲不被抹掉；不用命令或目標位置冒充砲位。
2. 每side以8×8粗區索引，每區只保留最近2×2子區、1–3次數、最後tick；同子區續射收斂，換子區重置。多砲同tick同粗區不同子區用固定子區順序解歧義，不依單位ID／陣列順序。每方最多8區，滿額丟最舊，同時刻用固定粗區順序，600tick邊界準確到期。
3. 全部持續狀態是World中的整數純資料並進hash；同種子／同指令、JSON紀錄、途中clone一致，舊世界缺欄位可接續。保留原SCRIPT與RNG消耗；移除新增情報欄位後原1200tick世界仍得main172dd372的f3364bb6，AI勝場與所有原守衛不變。golden只依完整unit實際輸出更新，Node／Chrome必須一致。
4. 同一2×2子區內任意精確發射位置產生相同情報／顯示；三級中心與半軸符合8×6→4×3→2×1.5格，面積下降、真實位置始終在圈內，最終仍有完整2×2格不確定性。公開投影不帶來源精確座標、單位ID或未公開子區；渲染不讀隱藏敵人的當前位置／存亡來移動或刪除圈。
5. 沒有新砲聲時，移動／死亡／進出視線不改歷史區域，只隨固定tick到期；新粗區開火時舊區仍保留至到期。小地圖敵單位點、主畫面模型、可見敵計數與點選仍用原可見性，不把估計區當精確目標鎖定。此條只約束一般遊玩畫面／輸入，不宣稱封鎖既有__rts除錯讀取。
6. 小地圖橢圓用世界採樣點經toMini投影並在菱形裁切，固定容量／採樣，不逐頂點夾邊。一般提示明示疑似／非精確；手機最小第三級圈在真實Chrome像素可辨識。換局、暫停、重播、同tick世界替換不殘留舊情報，畫面更新頻率與noR115開關不改世界或RNG。
7. 真實Chrome在412×860與1280×800驗證第一／第二／第三級、到期、換局與閥開關，保存相同tick／鏡頭的特寫。對固定較粗／較細、洩漏精確子區、跟隨隱藏單位、過期殘留、漏畫／漏裁切或閥失效等關鍵語意，用隔離負控制證明對應斷言先紅，不以啟動失敗算負控。全部既有守衛及120秒單支上限保留。
8. 只增加2D小地圖繪製，WebGL calls／triangles同世界不增加；手機開局≤20calls／80000triangles、既有熱點≤22／80000。新提示不蓋住操作列／生產列／小地圖，原生小地圖點擊仍正常，noR115回到舊顯示。看最新head桌機／手機四標準圖與情報特寫，不宣稱Android實機已測。
9. 首卡先推、驗收不改；typecheck／unit／build／smoke／main版lane逐項記錄，失敗照實寫。R114已知雙擊紅燈不以本卡另一次綠燈宣稱解決。卡面結果／未完成、方向待辦與卡住表、LOG完整；latest-head CI／Ready／最新main／精確head與合後main CI／Pages／公網核驗均遵守原門檻。
