## 為什麼做這張

R083 讓兩個人一起指揮我方打電腦（合作）。這一類遊戲最常玩的是兩個人對打。R084 先把引擎偏向一邊的地方修了（編隊、指揮部、出生格、集結點、尋路平手），這一張讓第二個人真的指揮另一方。

介面與畫面有上百處寫死「我方是第 0 方」：選得到誰、看得到誰（戰爭迷霧）、生產列、補給、血條、提示列、小地圖、勝負橫幅、戰報。

## 做什麼

1. **「我方」可以換**：新的 `src/side.ts` 匯出 `SIDE_PLAYER`、`SIDE_ENEMY` 兩個**活的**綁定（`export let`），預設跟模擬的一樣（0、1），`setViewSide(1)` 換成左上那一方。介面、畫面、總機（`src/ui`、`src/render`、`src/main.ts`）改成從這裡匯入；用到它們的那幾百行字一個都不改。模擬（`src/sim`）照舊從 `world.ts` 匯入——模擬不知道是誰在看。每開一局（`reset()`）先換回第 0 方。
2. **寫死 0／1 的介面**：勝負橫幅（`hud.ts`）、戰報的標題與「我方／敵方」兩欄（`reportView.ts`、`report.ts` 的開火與跳彈）、腳下的藍紅圈（藍＝我方）改成照「我方」。軍服的顏色照舊跟著陣營（右下橄欖綠、左上野戰灰）。
3. **連線對戰**：開始選單多一顆「連線對戰」，跟「連線合作」同一頁（標題與說明換成對戰）。房主照平常選地圖、布陣、開戰，指揮右下（第 0 方）；加入的人指揮左上（第 1 方），開戰時鏡頭在左上。對戰的局不叫電腦：房主開局的 `ai` 指令在送出去之前拿掉（自己的紀錄也拿掉）。左上那一方的布陣第一版用電腦的布陣。分享的連結：`?room=ABCD&net=host&vs=1`。房主選了喪屍模式或沙盒就照合作開（喪屍沒有左上那一方）。
4. **指令只收自己那一方的**：對戰時，鎖步第 1 步以後的包只留 `side` 等於那個玩家的指令（沒有 `side` 的也丟）；兩邊用同一個規則，結果一樣。第 0 步的開局不篩。合作照舊全收。
5. **停火兩方都能用（模擬，只在新開的局）**：模擬的停火資格以前只認第 0 方。R084 的 `sym`（新開的局才有）開著時第 1 方也算；沒有 `sym` 的局（舊重播、舊存檔、舊守衛）照舊只有第 0 方。介面的停火鍵送 `side: SIDE_PLAYER`（以前寫死 0）。
6. **狀態列**：「連線 ABCD｜對戰｜2 人…」。
7. **對戰的局不自動存**：存了之後「繼續上一局」會變成單機、左上那一方沒有人指揮。
8. 逃生閥 `?noR085=1`：開始選單沒有「連線對戰」、`vs=1` 不算數。`reset()` 照樣先換回第 0 方（沒有對戰時本來就是 0，閥關著也一樣，不另外判斷）。停火的模擬改動跟著 R084 的 `sym` 走（`?noR084=1` 關掉）。
