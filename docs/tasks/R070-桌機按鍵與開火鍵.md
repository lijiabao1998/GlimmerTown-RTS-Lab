## 為什麼做

桌機（滑鼠＋實體鍵盤）現在只有滑鼠拖曳、滾輪、空白鍵、Esc、右鍵；`R143` 的浮動「開火／停火」鍵是為手機拇指放的左側直欄，桌機擺在工具列下方、地圖左緣，既擋地圖又不像桌機 RTS 的操作方式。業主要求桌機去掉那顆鍵、WASD 平移、補上標準 RTS 按鍵。

## 做什麼

1. 新檔 `src/ui/keys.ts`：純函式（按鍵→動作、按住→每幀位移）＋ DOM 接線，跟 `src/ui/camera.ts` 一樣不碰世界。
2. `src/main.ts`：只加接線（`initDesktopKeys` 一處、主迴圈一行 `step(dt)`），新增的實際行為都在 `keys.ts`。
3. 桌機鍵表（`?noR070=1` 全部關掉）：

| 鍵 | 動作 |
|---|---|
| W A S D／↑ ← ↓ → | 平移鏡頭，按住連續移動（1100 CSS px／秒，斜走不加速），放開即停 |
| Q／E、+／− | 縮小／放大一格（1.12 倍，與滾輪同倍率，沿用 0.55–3 的既有範圍） |
| H | 鏡頭回我方指揮部（沒有指揮部時回我方單位重心） |
| F | 砲擊模式（與工具列「砲擊」同一顆鍵的動作） |
| G | 停火／開火（取代桌機那顆浮動鍵，指令與 R143 完全相同） |
| Ctrl+A | 全選我方 |
| 1–9／Ctrl+1–9 | 選群組／設定群組 |
| Tab | 下一個我方單位 |
| F1／? | 說明面板 |

   Space（暫停）與 Esc（取消選取）維持原本在 `main.ts` 的處理，不動。
4. `src/ui/fireDiscipline.ts`：新增 `toggleFireDiscipline()`（按鈕與 G 鍵共用同一段），並在桌機不建立那顆浮動鍵（`opts.show`）。
5. `src/valves.ts`：新增 `r070`。
6. `src/ui/help.ts`＋`index.html`：說明面板加「桌機按鍵」一段，`body.r070` 才顯示。
7. 守衛：新增 `tests/desktop-keys.mjs`（純函式）；改兩支既有瀏覽器守衛的**桌面段**判準（見「動到哪些既有守衛」）。

## 不改什麼

- 不改模擬（`src/sim`）、不改黃金雜湊、不加 npm 套件、不加外部素材。
- 不改任何手機尺寸的既有排版與 44px 斷言；不改 `#hud .btns` 的內容與順序。
- 不改手機預算（≤ 20 繪製呼叫／≤ 80,000 三角形）；DOM 多半一顆，繪製呼叫不變。
- 不改 Space／Esc 的既有行為，不改滑鼠拖曳、滾輪、右鍵、雙擊、框選。
- 不改 `tools/`（受保護檔案）。

## 驗收（動手前寫）

1. 桌機（`(hover: hover) and (pointer: fine)`）沒有 `#fire-discipline`；`?noR070=1` 時它回來，位置、尺寸與 1280×800 的舊 CSS 相同（44×44、不與工具列／小地圖重疊）。
2. 四種觸控尺寸（360×860、412×860、860×412、640×360）那顆鍵仍在、44px、可點；既有斷言不動。
3. 按住 W 或 ↑ 0.5 秒，鏡頭沿螢幕往上移 520–580 CSS px（1100 px/s × 0.5）；放開後下一幀位移 0。
4. W+D 對角同時按：一幀位移量與只按 W 相差 ≤ 2%（不能 √2 倍）；方向確實是右上。
5. 說明／戰報／開始選單開著時，按 WASD 鏡頭不動；關掉後同一顆鍵恢復作用。
6. Q 鍵一次放大 1.12 倍、E 一次縮小 1/1.12；連按 30 次不超出 `0.55 ≤ zoom ≤ 3`。
7. G 鍵與原本那顆鍵送出逐位相同的 `fireDiscipline` 指令（同 side、同 ids、同 hold），且 `?noR070=1` 時 G 鍵無效。
8. H／F／Ctrl+A／1（選群組）／Ctrl+1（設群組）／Tab／F1 各按一次都有可觀察結果（鏡頭移動、工具列狀態、選取數、說明面板）。
9. `?noR070=1` 時：沒有桌機按鍵、浮動鍵回來、`#hud .btns` 與 1280×800 的畫面與 `db9eedc` 相同（樣張對照）。
10. 只動 UI：`sim=no`、黃金雜湊 `eea1d59b` 不變。
11. `npm run typecheck`、`npm run unit`（含新守衛）、`npm run build` 綠；`tests/desktop-keys.mjs` 故意改壞一次會紅（卡面記數字）。
12. 說明面板有「桌機按鍵」一段；`?noR070=1` 時不顯示。
