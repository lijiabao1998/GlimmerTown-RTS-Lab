# R104［待辦 4］裝甲面向：繞到側後方

## 為什麼做
坦克正面交火之外，繞到側後方應有可理解的回報。車體的朝向和砲塔分開，玩家能從選取裝甲弧讀懂弱點。

## 做什麼
- 輕、中、重坦克保存整數車體方向；只由實際主動移動更新，碰撞推擠和砲塔瞄準不改車體方向。
- 穿甲彈以命中時車體方向和彈道起點判斷正面／側面／背面：原傷害先乘 75%／100%／125%，再套既有穿甲、兵種裝甲與掩體；間接高爆與步槍不套面向。
- 正、後各 90 度錐體，側面為其餘；以整數點積平方比較，不用浮點三角函式。沒有朝向欄位的舊世界用原傷害，移動後才有朝向。
- 選取我方裝甲單位時顯示正面與後方弧，?noR104=1 只關閉提示；重播格式不變。

## 不改什麼
不改 AI、步兵機制、鏡頭、光源、後製、全局畫風、手機預算、依賴或受保護工具。不刪既有機制，不變更舊指令欄位。

## 驗收（動手前寫）
1. 新建與生產的輕、中、重坦克有有效整數車體方向；主動移動更新，停車、砲塔轉向、推擠不改變該方向；缺欄位的舊世界仍能前進。
2. 穿甲命中正面／側面／背面的傷害符合 75%／100%／125%；四個旋轉方向及錐體邊界對稱；重坦克既有裝甲繼續生效；非裝甲、步槍、高爆不額外套面向倍率。
3. 舊指令紀錄 JSON 來回、重跑、中途 structuredClone 接續的雜湊一致；方向會折進世界雜湊；Node 與 Chrome 腳本結果一致。
4. 選取提示只顯示可見的我方裝甲單位，跟車體方向一致；?noR104=1 和 ?fx=off 關閉提示但模擬雜湊不變；畫面不改世界。
5. 保留既有守衛並跑 typecheck、unit、build、smoke；新守衛逐條故意弄壞驗證第一個紅燈；手機開局不超過 20 calls／80,000 三角形，戰鬥不超既有門檻。
6. 看桌機、手機開局與 30 秒樣張，另檢查裝甲弧特寫；卡面記實測數字、未跑或未完成項目；main 上的 gpt-lane 通過。
