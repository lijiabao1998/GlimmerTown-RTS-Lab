## 為什麼做這張

業主 2026-10-29 要開始選單與選單欄，電腦版、手機版都要。現在一打開（載入畫面之後）就直接進布陣，模式與地圖的入口是左上角四顆零散的鍵（沙盒模式、地圖、喪屍、96×96 河鎮）；手機直向這四顆加上具／產／框把左半邊擠滿。電腦難度只能用網址 `?ai=` 選，新手教學要先打開說明才找得到。

## 做什麼

1. **開始選單**（新檔 `src/ui/startMenu.ts`）：載入畫面消失後蓋在畫面上，後面的小鎮照常畫。內容：
   - 標題「微光小鎮·二戰 RTS」。
   - 地圖：萊伊 32×32／鄉間 64×64／河鎮 96×96（各自的閥開著才有）。
   - 模式：一般對戰／喪屍防守／沙盒（各自的閥開著才有）。
   - 電腦難度：簡單／普通／困難（一般對戰、電腦對手開著才有）。
   - 「開始」：關掉選單，進布陣第 0 步（沙盒則進沙盒）。
   - 新手教學（教學還沒做完才有）、怎麼玩、音效開關。
   - 選地圖或模式時，按的是原本那幾顆入口鍵（同一段程式），背後的小鎮當場換成那張地圖；結果跟按舊鍵完全一樣。
2. **選單鍵**：右上那排鍵最前面加「選單」。
   - 布陣時叫出開始選單。
   - 開戰後叫出暫停選單：繼續、重新開始、回主選單、怎麼玩、音效。打開時戰鬥暫停，模擬一步都不走；「繼續」回到打開前的暫停狀態；「回主選單」回布陣第 0 步並顯示開始選單。
   - 選單開著時，鍵盤（空白鍵等）與點地圖不會穿透到遊戲；Esc 等於「繼續」。
3. 閥開時，左上那四顆入口鍵不再顯示（收進選單）；沙盒面板裡的「離開」照舊。
4. 電腦難度：`main.ts` 的 `aiLevel` 改成可以被選單改；開戰時送出的電腦指令用選到的難度。網址 `?ai=` 照舊當初始值。
5. 守衛：
   - `tools/cdp.mjs` 的 `open()` 預設在網址加 `noR069=1`：既有守衛照舊測沒有選單的流程（它們寫的時候就是這個流程）；要測選單的守衛用 `open(query, { menu: true })`。`AGENTS.md` 寫明這條。
   - 新守衛 `tests/start-menu.mjs`（不開瀏覽器：選單內容怎麼隨模式、閥、教學狀態變）、`tests/start-menu-browser.mjs`（真 Chrome：桌機滑鼠、手機觸控）。
   - 煙霧測試（`tools/smoke.mjs`）加開始選單開局。
6. 順手：R068 卡面狀態改成已合併（#106）。

## 對其他車道的影響（照實寫）

- `tools/cdp.mjs` 是共用的開頁工具：之後 GPT 寫的瀏覽器守衛預設看不到選單；要測選單得明寫 `{ menu: true }`。
- 閥開時四顆入口鍵不顯示：測它們的既有守衛因為 `cdp.mjs` 預設帶 `noR069=1`，照舊看得到、照舊綠。
- `main.ts` 只加接線，行數不超過 `tools/hub-budget.json` 的上限 673。

   - 選「困難」後開戰，紀錄裡電腦指令 level 是 3；`?ai=3` 開頁時選單亮「困難」。
