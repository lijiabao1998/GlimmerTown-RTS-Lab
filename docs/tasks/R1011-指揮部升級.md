## 為什麼做

- 路線圖第 110 行與「Claude 線停在 R050」那一節都把「指揮部升級」列在 R050 第二段（跟沙包、修橋、排雷一起）。業主 2026-11-21：「12345全部做完，開始吧，流量是夠的」。
- 指揮部是整局唯一的要害：R019 起它倒了那一方就輸，R077 起倒了就馬上結束。現在玩家保護它只有一個辦法：把兵擋在前面。指揮部本身一局到底都是同一個 1,200 血的帳篷小屋。
- 1940 年的實際做法正好是兩件事：
  1. **把指揮所挖進去、堆沙包。** 營、旅的指揮所一停下來就加沙包牆、頂上堆沙包或土（防破片的掩蓋）。這是各兵種自己做的野戰工事，不是只有工兵做（英軍的野戰工事手冊書名就叫 *Field Engineering (All Arms)*，見「數字與出處」）。
  2. **把電話線拉起來。** 1940 年英軍的指揮靠電話線和傳令兵（無線電很少）；指揮部的通信室接上交換台，往上、往下都打得通，事情就快。線最常斷在砲擊：指揮部挨砲，線就斷。
- 這兩級給玩家一個「補給花在哪」的新選擇：多出一班兵，還是讓指揮部撐得久、出兵快；而且升級要讓指揮部停工一陣子，什麼時候做是個判斷。

### 2. 規則

#### 2.1 只在 `hq11`＝1 的局

- `eco` 指令多一個選填旗標 `hq11`（只認 1）。`startEco` 只在 `w.eco.tech`＝1 時存 `w.eco.hq11 = 1`（`tech` 本來就只在 `sw`＝2 時存；這張跟 R050 一起開關：頁面只在 `V.r050 && V.r1002 && V.r1011` 時送 `hq11`、放「指揮部」那一組，見 6）。
- `w.eco.hq11` 進雜湊：eco 那一行最後接 `if (e.hq11) f.int(0x4851).int(e.hq11);`。
- 喪屍防守、沙盒不開放（同 R050、R091、R1002）。

#### 2.2 下單：`{ t: 'produce', side, kind: 1201 | 1202 }`

不加新指令：`produce` 的 `kind` 本來就是整數，`commandCheck` 不用改形狀（`isCommand` 已經只收 `side` 0／1、`kind` 是 ±0x7fffffff 內的整數）。`eco.ts` 的 `produce()` 最前面多一行：`kind` 是 1201、1202 就交給 `order1011`，不走生產佇列。注意 `step.ts` 套指令時是 `cmd.side | 0`、`cmd.kind | 0`：形狀不對的東西（`kind` 1201.5、`side` '1'）只有 `isCommand` 擋得住（連線走 `lockstep.ts` 的 `put`、匯入的紀錄與存檔走 `checkLog`），模擬看到的已經是截過的整數——這是所有指令既有的分工，這張不改。

接不接（介面與模擬共用同一支 `why1011(w, side, kind)`，回 `''` 才接；照這個順序）：

1. `w.eco.hq11` 開著、不是喪屍防守、不是沙盒、還沒分勝負、`side` 是 0 或 1 → 不然「本局未開放」；
2. 這一方登記的指揮部（`w.eco.hq[side]`）還站著 → 不然「指揮部已毀」；
3. `kind` 是 1201 或 1202 → 不然「不能這樣升級」（介面看不到這一句）；
4. 這一棟沒有正在做的升級（`hqUp` 沒有）→ 不然「正在升級」；
5. 1201：還沒加固（`hqLv` 沒有）→ 不然「已經加固」；1202：已經加固、還沒有交換台（`hqLv`＝1）→ 沒加固「要先加固指揮部」、已經有「已經有交換台」；
6. 補給夠 → 不然「補給不足，還差 N」。

接了：扣補給、`hq.hqUp = 300`（或 400）。這一步沒有別的變化。

#### 2.3 做的那幾步、做好的那一步

`ecoStep` 裡，這一方的補給進帳（指揮部收入、R050 補給站）之後、讀生產佇列之前，多一行：

```ts
if (hq.hqUp !== undefined && tick1011(w, hq)) continue;   // R1011：升級中＝這一方生產暫停（佇列、進度留著）
```

`tick1011`：`hqUp` 減 1；還大於 0 就回 true（這一步暫停）。減到 0 的那一步：拿掉 `hqUp`、`hqLv` 加 1；升到 1 時 `maxHp += 600`、`hp += 600`；段數（`stageOf`）變了就照 R050 推一個 `stage` 事件；一律推一個新事件 `{ e: 'hq11', bld }`（畫面重建城鎮網格用）；這一步也算暫停，下一步恢復生產。

- 下單那一步就開始算：下單在第 t 步，第 t＋299 步做好，第 t＋300 步恢復生產（同 R050「第 400 步蓋好」的數法）。這是玩家、連線、紀錄裡的指令（`step()` 先套指令、再 `ecoStep`）；電腦的指令在 `ecoStep` **之後**才套（`step.ts` 第 540–547 行），以後電腦下單會是第 t＋300 步做好、第 t＋301 步恢復——守衛照指令來源分開算。
- 指揮部在做的時候倒了：那一方本來就輸（R019／R077）；`hqUp` 留在瓦礫上，存檔照收。
- 血只在做好那一步一次加 600，不是慢慢長（不是工地）。血與上限一起加，所以段數只會變好或不變：重損（沒屋頂）的指揮部做好加固，可能回到完好。

#### 2.4 交換台

`ecoStep` 讀到佇列最前面那一個、還沒開工時（`e.prog[side]`＝0），在 R095 那一行（`if (e.prog[side] < ticksOf(q[0]))`，守衛錨著，不動）**前面**多一行：

```ts
if (e.prog[side] === 0 && phone1011(w, hq)) e.prog[side] = ticksOf(q[0]) >> 2;   // R1011 交換台：開工那一步先做好四分之一（線斷了不算）
```

`phone1011`：`w.eco.hq11`＝1、`hq.hqLv`＝2、`stageOf(hq) === STAGE_INTACT`（血 × 10 > 上限 × 7；跟 R127 的「完好」不是同一件事：1,500/1,800 在 R127 寫「受損」，線照樣通）。只看開工那一刻：做到一半斷線或接上，這一個不改。

- 「開工那一步」＝佇列不空、`e.prog[side]` 是 0 的那一步：上一個出生時 `prog` 歸 0、下一步就是下一個的開工步；暫停那一行在前面 `continue`，所以暫停中不會算到開工。開工那一步在同一步裡接著被 R095 那一行加 1，所以從開工到出生是 T − ⌊T/4⌋ 步（不是 T − ⌊T/4⌋ − 1）。

- 用「開工先做好四分之一」而不是「每幾步多做一步」：R125 的倒數（`T − prog`）、R095 的進度條（`progMax95`）一個字都不用改，倒數秒數就是真的；進度條開工就是四分之一，看得出交換台省掉了一段。
- 換成白話：要人要車的電話直接打到後方，省掉傳令兵跑的那一段；省的是「傳話」，不是造得比較快。

### 3. 為什麼用生產列直接買，不叫工兵蓋

- **史實**：沙包是各兵種自己堆的（指揮部的人、警衛排）；交換台是通信兵接的：營以下是營自己的通信排（步兵的通信員），旅以上才是皇家通信兵；皇家通信兵 1920 年從皇家工兵分出去。工兵在 1940 年忙的是障礙、爆破、橋。叫工兵去接電話線反而不像。
- **玩法**：升級的代價是「指揮部停工一陣子」，這比「再派一個工兵走過去」更是個判斷；也不會出現「蓋到一半的指揮部」這種奇怪的狀態。
- **程式**：不碰 R050 的 `construct`、`why50`、`build50`、`w.tech.sites`、`techOk`，也不碰 R1002 的爆破路由（工兵點自己的指揮部是蓋還是炸，這個問題根本不會出現）。

### 史實（給數字的方向，不給數字本身；都是我記得的出處，施工時再核對一次）

1. **沙包是各兵種的事**：英國陸軍《Military Training Pamphlet No. 30 — Field Engineering (All Arms)》（二戰期間的野戰工事手冊系列）：塹壕、掩體、沙包牆、頂蓋由各兵種自己做，皇家工兵負責技術、障礙、爆破。版本與頁碼沒核對。
2. **防破片與防砲彈**：英軍野戰工事的用語分「防破片（splinter-proof）」與「防砲彈（shell-proof）」；沙包牆加薄頂蓋只算防破片，擋得住子彈和破片、擋不住榴彈直接命中。這張把它全部折成血量（不分彈種，見沒做成的事 4）。
3. **沙包擋子彈要多厚**：英軍 MTP 30、美軍 FM 5-15《Field Fortifications》都有「多厚的沙包或土擋得住步槍、機槍子彈」的表，量級是半公尺到一公尺（隨距離、土質變）。確切數字沒核對，所以不拿來定遊戲的數。
4. **電話是通信兵的事**：皇家通信兵（Royal Corps of Signals）1920 年 6 月以皇家授權書從皇家工兵的通信勤務分出來（英文維基「Royal Corps of Signals」）。但營以下的線是營自己接的：1938 年改編後英軍步兵營的營部連第 1 排就是通信排（步兵的通信員，不是皇家通信兵；英文維基「British Army during the Second World War」一類的編制敘述，記憶，未逐句核對）；皇家通信兵管的是旅、師以上。遊戲裡的指揮部大約是營、旅之間，兩種說法都說得通，畫面與文字都不寫兵種。
5. **1940 年的器材**：野戰電話 D Mk V、交換台（10 線那一型，型號記憶中是「UC 10 line」）、雙絞的野戰電纜 D3、防竊聽的 Fullerphone（英文維基「Fullerphone」：一戰時 Algernon Fuller 發明、二戰照用）。D Mk V、UC 10、D3 是記憶中的型號，未核對；畫面不寫型號，只畫一根桿、一盤線。
6. **1940 年 5 月的教訓**：英國遠征軍的指揮多半靠電話線（含法國的民用電話網）和摩托車傳令兵，無線電少；指揮部一搬家、線一斷就失聯（英文維基「British Expeditionary Force (World War II)」「Battle of France」的敘述，記憶，未逐句核對）。這是「交換台讓事情快」「挨砲就斷線」兩條規則的來源。
7. **砲擊打斷電話線**：一戰到二戰最常見的通信中斷，前線的架線班就是在砲火下補線（一般史實，不附單一出處）。這張沒有「補線」（見沒做成的事 3）。
