## 為什麼做

業主選擇「帝模式也就是沙盒模式」。本次以此取代下一個 UI 小題，先交付可以反覆放兵與觀察既有對轟的最小切片。2026-10-22 fetch 後 main 為 d8b2f97；main 卡片、LOG、歷史及所有 origin/gpt/* 分支最大號 R127。唯一 open PR47／R114 已卡住，保留原狀。

## 做什麼

獨立模式沿用既有 32×32 程序村莊、坦克與榴彈砲及其數值。初始沒有單位、補給或電腦指揮，暫停；可以選雙方、單位種類，在空格放置。我方沿用既有指揮，敵方只沿用單位原有還擊。總共最多建立 32 個單位（含殘骸，重置清空）；滿額與不合法位置明示原因。

所有放置、開始、暫停、重置都由固定 step 套用新指令。沙盒保存獨立指令步序；戰鬥 tick 只在運行時前進，因此暫停編輯不偷跑戰鬥。沙盒重播須明確選擇沙盒初始世界，普通世界拒絕新指令。重置保留單調指令步序、還原同種子地圖與空軍力暫停局。
