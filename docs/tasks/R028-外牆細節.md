## 為什麼做這張

Rye 與東南英格蘭小鎮的街景有三種一眼認得出的外牆：**木構**（timber-framed：米白灰泥牆上露出深色橡木框架，Mermaid Street 那種）、**掛瓦**（tile-hung：二樓以上掛一片片紅陶瓦，薩塞克斯與肯特的招牌）、**白色護牆板**（weatherboarding：一條條橫木板）。現在所有磚房同一個樣子，整條街像複製貼上。

## 做什麼（只有畫面）

1. 磚房與店面依建築編號（雜湊，固定）分三種外牆：紅磚（原樣）、木構、掛瓦（兩層以上才掛）；農舍一半畫白色護牆板的橫線。
2. 全部畫進既有的城鎮合併網格（多一些方塊），**不加繪製呼叫**；三角形增加要在預算內。
3. 倒塌殘影（R004）、彈痕（R014）照用同一支模型。
4. **逃生閥** `?noR028=1`：全部回到紅磚原樣。

## 不改什麼

- 模擬、雜湊、黃金都不碰（`98dc0f18`）；建築的大小、高度、窗戶位置不變（射線落點與屋頂高度不變）。

## 驗收（動手前寫）

1. `npm run check` 本機與 CI 全綠；黃金雜湊不變。
2. `tests/facades.mjs`：
   - 同一棟房子每次畫出來一樣（固定）；三種外牆在 Rye 地圖上都出現；關掉時跟原樣逐頂點相同。
   - 外牆細節不改建築的外框（包圍盒最多外擴 0.02 格），屋頂高度不變。
   - 整張 Rye 地圖的城鎮網格三角形 ≤ 40,000。
3. 煙霧測試：手機開局繪製呼叫、三角形在預算內；`?noR028=1` 雜湊不變、開局三角形比開著少。
4. 每條新守衛故意弄壞一次，第一個紅燈落在它身上（記在卡面）。
