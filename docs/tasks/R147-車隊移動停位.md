# R147　車隊移動停位（待辦 45）
<!-- card: sim=no; golden=無; valve=?noR147; owner_ok=業主指定先做待辦 45 -->

## 為什麼做

多選車輛或火砲點地面時，原來只在點擊處閃一個圓圈。玩家需要看到整隊在地圖上的實際停位，也要分得出幾輛車擠在同一格。

## 做什麼

我方多人車隊的移動指令執行時，讀取遊戲已算好的路徑，在地面短暫標出各車砲的終點。同格顯示數量。鏡頭移動時標記跟著地圖，讓滑鼠與觸控繼續操作戰場。

## 不改什麼

沿用現有選取、編隊、尋路、移動指令、存檔與重播格式。

## 驗收（動手前寫）

1. 桌面與直式觸控從遊戲畫面下達多車移動，出現對應的地面標記。用獨立讀取的路徑終點核對停位，包含繞不到目標的情況與同格數量。
2. 單車、徒步單位、敵方指令不產生車隊標記。替換指令、新局與顯示時限都能清掉舊標記。標記跟隨鏡頭並讓點擊穿透。
3. `?noR147=1` 關閉標記，同一組輸入的模擬雜湊與記錄相同。保留桌面與手機尺寸截圖，現有 CI（含 smoke、gpt-lane）通過。

## 施工紀錄

基線 `cef0395`。介面在指令執行後讀取各車最後一個可達路徑格。停在原地的單位使用所在格。地圖上的菱形旁顯示單位編號，多輛共格顯示 × 和數量。標記放在 HUD 底層，兩秒後消退。

負對照在隔離副本把路徑終點替換成要求的目標格，`move-destinations` 如期在被牆隔開的案例報錯。原版本通過。

## 驗收結果

- 本機型別檢查、正式建置、停位邏輯、閥表與總機行數守衛通過。黃金檔維持 `eea1d59b`。
- Windows Chrome 桌面 1280×800 與直式 412×860 均從「全選」下令，4 輛車砲的標記位置與遊戲路徑逐一相符。已核對平移、點擊穿透、消退與換令，並保留兩個尺寸的遊戲截圖。完整 Linux 分片、smoke 與四張標準樣張見本卡 PR 的 CI 附件。

### 沒做成的事

標記顯示指令執行時的停位。指令在暫停或連線佇列裡會等遊戲執行；隨後的地形變化有機會改變行進路徑。手機尺寸用桌面 Chrome 觸控模擬驗收。
