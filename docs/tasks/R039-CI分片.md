## 做什麼

1. `tools/unit.mjs` 支援分片：環境變數 `UNIT_SHARD=k/n`。
   - 沒設＝跟現在一模一樣（本機 `npm run unit` 不變）。
   - 第 k 份只跑分給它的 `tests/*.mjs`；內建的第 1–3、5 節（純度、零外部素材、模擬行為、決定性與黃金雜湊）只在第 1 份跑。
   - 分法固定、跟機器無關：先把開瀏覽器的守衛（檔名以 `-browser.mjs` 結尾，或內容 import `withBrowser`／`tools/cdp.mjs`）照檔名排序輪流分，其他守衛接著輪流分。每支守衛剛好在一份裡。
   - 開頭印出「分片 k/n：這一份跑哪幾支」。
2. `.github/workflows/ci.yml`：
   - `unit`：四份並行（matrix 1–4），每份 20 分鐘上限；第 1 份另外跑 typecheck；每份把 `shots/*.png` 與 unit 紀錄上傳成 `unit-<k>-<sha>`。

   - `pages` 等 `smoke`。`gpt-lane` 不動。
