# R148　手機左側的全排與搭車（待辦 48）
<!-- card: sim=no; golden=無; valve=?noR901; owner_ok=業主指定接在待辦 45 後面 -->

## 為什麼做

步兵旁有空車時，「全排」和「搭車」會一起出現。兩顆按鍵原本往畫面中央伸出，手指在戰場選點時很容易碰到。

## 做什麼

直式手機的左側指令列上方放「全排」、下方放「搭車」。兩鍵與相鄰的工具開關保有獨立觸控範圍，使用不同高度的手機都能選到。

## 不改什麼

沿用原本的顯示資格、選取規則、橫向排列與桌面快捷鍵。

## 驗收（動手前寫）

1. 360 和 412 像素寬的直式觸控視窗都能同時看到兩鍵，左緣對齊安全區，觸控面至少 44×44 CSS 像素、上下間距至少 4 像素，中心與內側四角皆可點。另測窄短畫面以及 860×412 橫向。
2. 在同一局選步兵班後，實際點「全排」選到三班，再點「搭車」把附近空車加入選取。切換工具、生產選單後兩鍵仍可操作；空選取會收起按鍵。
3. 新版面守衛在原來的排列會報錯。桌機 Chrome 的手機尺寸截圖由本機 NPU 做中文辨識；另遮住第二字做負對照，完整文字才可通過。
4. 完整 CI，包括原有的手機、空中鍵、運輸、步兵排與 smoke 守衛全綠，再合併。
