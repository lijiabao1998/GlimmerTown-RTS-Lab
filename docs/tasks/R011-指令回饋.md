## 為什麼做這張

下了指令之後，地面標記 0.8 秒就消失；選了一群車，看不出誰在往哪走、誰在打誰、榴彈砲正在轟哪一格。RTS 的手感有一半是「看得懂自己的部隊在做什麼」（R003 手感門檻：指令回饋）。

## 做什麼（只改畫面）

1. **路線**：被選取的我方單位，地上畫出它剩下的路（從車到終點的一串短虛線，越遠越淡），終點一個小方塊；移動＝綠。
2. **攻擊線**：被選取的我方單位有攻擊指令時，從車拉一條紅色虛線到目標（看得到就畫到目標身上；看不到就畫到最後已知位置——那是玩家自己知道的資訊，不洩漏）。
3. **砲擊目標**：被選取的單位有砲擊指令時，從車拉一條橘色虛線到目標格，目標格畫一個十字準星。
4. 只畫被選取的我方單位（敵方的指令永遠不畫）。全部用一個實例化網格（地面短線片），有選取才有實例；開局不加繪製呼叫。
