## 做什麼

### 1. 旗標：機槍組第二版（`eco` 指令的 `mg: 2`）

- 新開的局送 `mg: 2`。帶 `mg: 1` 的紀錄（R080 合併之後到這張卡之前開的局）與沒帶 `mg` 的紀錄逐位不變。
- 逃生閥 `?noR081=1`：送 `mg: 1`（回到 R080 合併時的機槍組），也關掉第 5 節的「再點一次換下一個」。`?noR080=1` 照舊是完全沒有機槍組。
- 雜湊本來就把 `mg` 的值折進去，`mg: 2` 跟 `mg: 1` 的世界雜湊不同。

### 2. 鐵絲網（`mg: 2`）

機槍組算徒步單位：完整的鐵絲網擋得住，要繞（跟步兵、迫擊砲、觀測員一樣）。

### 3. 打在房子上的點射（`mg: 2`）

機槍組的點射被房子擋下時，只壓屋裡的**敵人**，不壓自己人。步槍、直射砲打在房子上照舊不分敵我（R052 的規則，這張卡不動；寫進「沒做成的事」）。

### 4. 電腦第三版的機槍組（`mg: 2`）

- **只挑打得到的**：機槍組自己到目標之間沒有房子、沒有稜線；或者目標就進駐在射線上的第一棟房子裡（打那棟房子就是在壓它）。其餘照舊：先壓還沒被釘住的，再比遠近。
- **打不到就換位置**：射程內有看得到的軟目標，卻都被房子或稜線擋住 → 往自己 3 格內、看得到其中最近那個目標的空格移過去；找不到這種格子就照舊跟著主力。
- **集結時不走開**：電腦在基地等波次的時候，射程內有打得到的目標的機槍組留下來打，不被叫去集結點。
- **對付機槍組也要打得到**：坦克等直射的車被派去打對方的機槍組時，只挑自己打得到的（射線上沒有房子、沒有稜線）。
- **經典規則不打進目標的房子**（合併前的審查之後加的）：沒有士氣規則時，點射打進房子只扣房子 1 點（碉堡 0 點），屋裡的人不受影響；所以「目標就進駐在第一棟房子裡」只在有士氣規則時算打得到。
- **換位置挑走得到的**（審查之後加的）：候選的格子照「走幾步到得了」排（6 步內；八方向、不切過擋路格的角、房子與鐵絲網擋路，跟尋路同一套規則），平手才比直線距離；隔著鐵絲網要繞遠路的格子不挑。

### 5. 介面（不動模擬）

- **疊在一起點得到**：同一個位置隔一下（超過 0.35 秒）再點一次，換選疊在那裡的下一個我方單位（照編號輪流）。很快地連點兩下照舊是「鏡頭跟過去」（R037）。
  審查之後補的：只有點到的最近那一個是我方的才換——疊著的旁邊的敵人照樣點得到、照樣是攻擊；很快地連點的第二下留在第一下選到的那一個（第一下照常換選），鏡頭照樣跟過去；右鍵下指令、長按（砲擊選單）不換選。
- **戰報的開局**：第 0 步補給送的單位（R021 的步兵班、機槍組）算進「開局」，擊毀與損失不再一開局就是 −1、−2。
  審查之後補的：擊毀與損失改成數雙方真的陣亡了幾個（舊的算法是「開局減還活著的」，中途造了新的就少算、甚至是負的；R019 以來就是這樣）；存檔記得這兩個數。

### 6. 守衛：釘住帶蘇聯、國際兵種的舊紀錄

複查跑了 51 份帶 `soviet`、`international` 的舊紀錄，全部逐位相同，但倉庫裡沒有守衛釘住它們。這張卡寫一支：幾局下令造蘇聯、國際兵種的對戰，終點雜湊寫死（在這張卡之前的 main 上算）。

**動手時改過的地方：**

- 「再點一次換下一個」第一版用 `performance.now()` 減上一次點按的事件時間，瀏覽器守衛抓到很快連點兩下也會換——事件時間跟 `performance.now()` 不一定同一個時鐘。改成由 `tap()` 把自己收到的事件時間傳進去。瀏覽器守衛的兩下點按也改用帶時間戳的觸控序列（R037 的作法），不跟著機器忙不忙變。

### 沒做成的事

1. **打中目標的點射總數比第一版少**（擬真 656 → 523、經典有效的 503 → 444）。第二版不再浪費子彈，但也因為更挑而打得少；壓制的效果在村莊差不多、在萊伊變好。試過放大換位置的範圍、放寬跟主力的距離，都沒有更好。
2. **步槍、直射砲打在房子上照舊不分敵我**（R052 的規則）。這張卡只改了機槍組；改步槍與砲會讓 R052、R075 的舊紀錄對不上，要另一張卡、另一個旗標。
3. **大地圖上機槍組照舊很少開火**（一直跟著主力走、停不下來架槍）。96 格兩局，兩版一模一樣，機槍組一發都沒開；64 格種子 2 兩版都打不完；64 格種子 1 第一版第 7,622 步分出勝負、第二版打不完——同一局中途走岔了，不是換位置一直換（連續的短距離移動最多 3 次就開火，跟第一版一樣）。這張卡沒有處理大地圖。
4. 疊在一起的單位只在「唯一選著的就在那一群裡」時輪流；框選不受影響。很快地連點兩下時，選的是第一下選到的那一個：第一下照常換選，所以選著步兵班時連點兩下，會換成機槍組、鏡頭跟過去。桌機 Shift＋點疊著的那一點，會把疊著的下一個加進來（審查的反方認為這不算錯，照實寫下）。電腦這邊的開局步兵班與機槍組照樣疊在同一點（模擬沒有動）。
5. **電腦簡單難度仍有一成多的點射打牆**（12.8%，第一版 64%；普通 1.0%、困難 0%）：每 4.5 秒才想一次，目標在兩次之間躲到房子後面，攻擊指令照舊對著最後看到的位置打。
6. 電腦的生產照舊把開局的機槍組算成支援（R080 更正第 8 條）；喪屍防守照舊送一組沒什麼用的機槍組。
7. 機槍組照舊沒有聲音；數字照舊沒有出處表；架槍不花時間、掃射區是圓的——這些在 R080 的更正裡寫了，這張卡沒有改。
8. 量測「會用對不會用」的開關只在暫存副本上，主線沒有；驗收 12 沒有守衛。
9. 換位置只找 3 格內、6 步走得到的；更遠的照舊跟主力。
10. R081 之前的存檔讀回來，戰報的擊毀與損失照舊用「開局減還活著的」算（存檔裡沒有陣亡數）。
11. 只量了電腦對電腦，沒有人實際玩過。
