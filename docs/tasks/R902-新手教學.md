# R902 三分鐘腳本式新手教學
<!-- card: sim=no; golden=無; valve=?noR902=1; owner_ok= -->

**狀態**：施工完，等 CI
**基線**：`origin/main`（黃金雜湊 `eea1d59b`）

## 為什麼做這張

第一次進遊戲，畫面上沒有一段會自己往下走的引導。說明面板要自己點「？」，而且一次把布陣、選取、砲擊全部講完。新玩家需要一段固定腳本，照順序把四件事各做一次：移動、採集、建造、攻擊。

## 做什麼

1. 新的教學腳本，跟 `src/sim/script.ts` 的 `SCRIPT` 分開。時鐘 20 步／秒、共 3600 步（3 分鐘）：移動 40 秒、採集 40 秒、建造 50 秒、攻擊 50 秒。玩家沒做完當前這一動，腳本就停在這一課，不會跳過。
2. 教學是一塊自己的小演練（選我方、移到空地、採補給、選農舍再蓋、點敵人），不把指令寫進對戰世界，所以既有腳本戰鬥與黃金雜湊不變。畫面上的字會對照戰場上真正的操作：點單位再點地面、指揮部補給、布陣蓋房子、點敵人攻擊。
3. 介面比照說明面板：第一次進（本機沒有 `gtrts.v1.tutorial`）就出現；「跳過」立刻收掉並記下；四課都走完記下完成，再進不再出現。「知道了」只關掉完成畫面。
4. 逃生閥 `?noR902=1`：不建立面板、不讀寫那筆本機紀錄。

## 不改什麼

- 不改 `src/sim/script.ts` 的 `SCRIPT`、`src/sim/step.ts`、`src/sim/world.ts`、`src/sim/ai.ts`、`src/render/post.ts`、`src/render/battle.ts`、`tools/`、黃金雜湊。
- 不加 npm 套件、不加外部素材、不加 WebGL 繪製呼叫。
- 不改既有檔名，不把總機裡的東西搬來搬去。`main.ts` 只加接線，行數仍低於 `tools/hub-budget.json` 的上限。

## 驗收（動手前寫）

1. `npm run typecheck`、`npm run unit`、`npm run build` 綠。`npm run smoke` 本機能跑就跑；跑不了就在卡面寫明，靠 CI。黃金雜湊仍是 `eea1d59b`。Node 與這張卡的守衛都要看到腳本戰鬥雜湊沒變。
2. `SCRIPT` 的 tick 序列仍是 0、0、240、240、500、500、700、900。教學檔不 import `script.ts`，也不呼叫 `runScript`。
3. 教學腳本走完：3600 tick、第 4 課結束、四個旗標都立起、補給 8、已建造、已攻擊、沒有被跳過。什麼都不做時停在第 0 課的最後一步（tick 799）。只做完移動就停在採集那一課。攻擊若做在移動之前不算。跳過之後時鐘不再走，而且不算完成。
4. `?noR902=1` 時 `initTutorial(..., false)` 不掛上面板、不寫紀錄。有 `done` 或 `skip` 紀錄時不再出現。面板上四課標題順序是移動、採集、建造、攻擊，並且有「跳過」。
5. 真的頁面：第一次進看得到教學；點得完第一動；跳過後面板收起；`?noR902=1` 沒有 `#tutorial`。教學開著時，既有的「開戰」、模式鍵、以及煙霧測試要點的畫布格仍點得到（繪製呼叫與三角形預算不因這張 DOM 卡增加）。
6. 新守衛至少弄壞一次，第一個紅燈落在它自己的斷言上，記在下面。

### 沒做成的事

教學不把移動、採集、建造、攻擊寫進對戰世界，玩家不是在真的地圖上被帶著做完這四件事；旁邊的小演練用文字對照真正的點法。直向面板為了讓開戰命令條中心和對焦後的畫布格仍點得到，寬度停在中線左邊，課文大約兩行，其餘要捲。高 ≤ 500 的畫面把時鐘藏起來，課文再短一截。本機是 Node 22（CI 是 24）；`facades`、`materials-view`、`damage-readability` 的凍結幾何雜湊在這台機器對不上，這張卡沒改那些檔。沒在實機手機上看。
