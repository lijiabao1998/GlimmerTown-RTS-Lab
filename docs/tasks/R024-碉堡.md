## 為什麼做這張

1940 年夏天英國為了防登陸，在東南沿岸與內陸「停止線」蓋了上萬座 **Type 22 碉堡**：矮、六角形、混凝土、每面一個槍眼。玩家布陣時現在只能蓋農舍、磚房、穀倉——加一座碉堡，「守」才有真正的工具，也讓 R022 的榴彈砲／迫擊砲有該砸的東西。

## 做什麼

1. **碉堡**（布陣 3 點，1×1）：混凝土，耐久 400；步兵、觀測員可以進駐，**在裡面只吃四分之一傷害**（房子是一半）。
2. **直射（坦克、反戰車砲、步槍）打碉堡只刮掉四分之一**；榴彈砲、迫擊砲全吃——碉堡剋步兵、怕砲。
3. 模型：矮六角（方塊拼出切角）、四面槍眼、頂板外挑、後面一段沙包；打壞時頂板裂一半。建築網格本來就合併成一個，**不加繪製呼叫**。
4. 敵方布陣（R006）也可能蓋碉堡；`enemyPlan` 多一個「可以蓋哪些」的參數，預設是原本三種（關掉 R024 時跟以前一模一樣）。
5. **逃生閥** `?noR024=1`：布陣列沒有碉堡、敵方不蓋。

## 不改什麼

- 既有建築的耐久與受傷規則不變；腳本戰鬥與黃金雜湊不變（`98dc0f18`）。
- 龍牙（擋車不擋人）與鐵絲網要「車與人走不同的路」，這張不做（見「沒做成的事」）。

## 驗收（動手前寫）

1. `npm run check` 本機與 CI 全綠；黃金雜湊仍是 `98dc0f18`；Node＝Chrome。
2. `tests/pillbox.mjs`：
   - 碉堡裡的步兵吃坦克一發＝全額的四分之一；房子裡＝一半。
   - 坦克直射打碉堡＝打建築傷害的四分之一；打房子全額；榴彈砲打碉堡全額。
   - 布陣：碉堡 3 點、可以蓋；`enemyPlan` 不給碉堡時跟預設一樣、永遠不蓋；給了會蓋（多個種子裡至少一個）。
   - 決定性：含碉堡布陣的紀錄重跑、JSON 來回、中途深拷貝相同。
   - 模型：完好與打壞各有自己的樣子、不是房子的模型、高度不到 0.4 格。
3. 煙霧測試：布陣列有「碉堡」（≥ 44 像素）、真觸控選了能蓋；開局繪製呼叫仍在預算內；`?noR024=1` 沒有碉堡、雜湊不變。
4. 每條新守衛故意弄壞一次，第一個紅燈落在它身上（記在卡面）。
