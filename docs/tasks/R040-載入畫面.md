## 為什麼做這張

- 打開網頁要等整份 `dist/index.html`（720 KB，gzip 後 201 KB）下載完才看得到東西。本機 Chromium 量到手機尺寸從打開到可以玩約 3 秒；手機網路更久。這段時間畫面是一片暗綠，不知道是在載入還是壞了。
- 原因：`vite-plugin-singlefile` 把 707 KB 的程式整段塞在 `<head>` 裡，`<body>` 排在它後面，瀏覽器要讀完整段程式碼才開始畫 body。
- 「要求能跑的起來」：手機不支援 WebGL、或程式在初始化時出錯，現在只會停在空白畫面。載入畫面要能把原因寫出來。

## 做什麼

1. `index.html` 的 `<body>` 一開頭放載入畫面：
   - 一台像素風的小坦克（程式畫的 SVG，跟遊戲同一套像素風與我方橄欖綠，沒有徽記），停在畫面中央。腳下的路往後捲，車身上下輕晃，排氣冒出小煙團。
   - 下面三行字：「微光小鎮」、「二戰戰術 · 1940」、「正在整備戰場」。
   - 不用光暈、漸層大字、驚嘆號（R041 要拿掉的那種）。
   - 動畫只用 `transform`／`opacity`，主執行緒忙著解析程式時也照樣動。系統設定「減少動態效果」時不動。
   - 整個載入畫面不吃點擊（`pointer-events: none`）。
2. `vite.config.ts` 加一個小外掛（不加 npm 套件）：建置後把內嵌的 `<script type="module">` 從 `<head>` 搬到 `</body>` 前面，載入畫面就排在程式碼前面先畫出來。module 腳本本來就是等 HTML 解析完才執行，搬位置不改執行時機。
3. 載入畫面後面接一小段內嵌的一般 `<script>`：
   - `?noR040=1` 時立刻拿掉載入畫面；
   - 程式還沒準備好就出錯（例如沒有 WebGL）時，把「正在整備戰場」換成「載入失敗：<錯誤訊息>」與建議（重新整理、換瀏覽器）。
4. `src/main.ts` 初始化做完、在設 `window.__rts`（守衛等的「準備好了」）之前，同一步把載入畫面拿掉。守衛看到「準備好了」的那一刻畫面上已經沒有它，不會出現在樣張或擋住點擊。
5. 守衛：
   - `tests/loader.mjs`（Node）：真的建置一份到暫存資料夾。驗：
     - 載入畫面在 module 腳本之前；
     - module 腳本在 `<body>` 裡，而且只有一段；
     - 內嵌的閥／錯誤腳本在 module 腳本之前；
     - 有「減少動態效果」的規則；
     - 載入畫面的樣式沒有 `text-shadow`、`filter`、漸層文字。
   - `tools/smoke.mjs` 加「R040」一節：
     - 載入畫面特寫：把 module 腳本拿掉的頁面，手機與桌機各一張樣張，坦克在動、字在中間、零外部請求；
     - 錯誤路徑：module 腳本換成一行丟錯，看到「載入失敗」；
     - 正常打開：準備好的時候載入畫面已經不在；
     - `?noR040=1`：沒有載入畫面、雜湊不變。

## 不改什麼

- 模擬、指令、黃金雜湊都不動；遊戲畫面、HUD、手機預算不動（載入畫面是 DOM，不加 WebGL 呼叫）。
- 不加 npm 套件、不加外部素材。

## 施工紀錄

1. 卡面先推：`6d7ede7`（只有這張卡）。
2. `index.html`：`<style>` 加載入畫面的樣式（`#loader`，z-index 100、`pointer-events: none`；動畫 `ld-road`／`ld-bob`／`ld-puff` 只動 transform／opacity；`prefers-reduced-motion` 時不動）；`<body>` 一開頭放載入畫面（SVG 32×16 像素坦克，放大 3 倍、`crispEdges`，顏色取我方橄欖綠 `#5d6b3a` 一系，沒有徽記）；後面接內嵌一般腳本：`?noR040=1` 拿掉載入畫面，`error`／`unhandledrejection` 在載入畫面還在時改寫成「載入失敗：…請重新整理，或換一個支援 WebGL 的瀏覽器。」。

4. `src/main.ts`：設 `window.__rts` 之前一行 `document.getElementById('loader')?.remove()`。
5. `tests/loader.mjs`：建置到暫存資料夾驗產物順序、閥／錯誤腳本位置、減少動態效果、沒有光暈濾鏡漸層字、動畫只動 transform／opacity、不吃點擊、main.ts 拿掉的位置。
6. `tools/smoke.mjs` 加 R040 一節（埠 9471–9531）：
   - 載入畫面特寫用 overlay 把 module 腳本拿掉；
   - 錯誤路徑把 module 腳本換成一行丟錯；
   - 「準備好的那一刻」用 preload 在頁面腳本之前掛 `__rts` 的 setter，記下設值當下載入畫面在不在。
7. 本機（Node 24.22.1）：
   - typecheck 綠；`tests/loader.mjs`、`tests/audio-ui.mjs`、`tests/readme.mjs`、`tests/production-block-reason-browser.mjs`（會另外建置變體）都退出碼 0。
