原則：
- **世界低彩度、資訊高彩度。** 地面、建築、軍服都在灰褐綠；只有陣營圈、選取、裝甲提示、火光用飽和色。新東西照這個分層。
- 單位模型用**頂點色白色吃實例色**（陣營色），深色、鋼色保留原色（`unitArt.ts` 的做法）。
- 提案（等業主）：加一組「雪地／冬季」地形色，以及色盲安全的陣營圈替代色（藍 `0x3b7fd6` 保留，敵方紅改橙 `0xe08a3a`，此色已出現在程式中）。

## 2. 光影
- 現況：`HemisphereLight(0xe4ecff, 0x5b5444, 1.35)` 加 `DirectionalLight(0xfff1d6, 2.1)`，陰影圖 2048²；鏡頭固定不轉，**光永遠從畫面左上來**（`battle.ts` 註解，承 2D 線 T745）。
- 材質一律 Lambert／頂點色，不用貼圖光照；新模型不要依賴高光。
- 光的方向、強度屬全局觀感，不在美術卡裡改。

## 3. 輪廓與剪影可讀性
- 程式裡**沒有描邊 pass**；可讀性靠剪影：每種單位至少一個往外伸的特徵（砲管、架尾、步槍、天線），並在頂部放亮一階的 MID 色塊當「頭」。
- 手機縮小時以 412×860 開局視角檢查：同陣營兩種單位要靠剪影分得出來，不靠顏色。
- 不加後製描邊（會動 `post.ts`，且吃預算）。

## 4. 陣營色
- 軍服／車身吃 SIDE_COL；判斷敵我主要靠腳下圈 TEAM_COL。
- 徽記只用程序生成的通用幾何與顏色；不畫卐字、SS 符文、真實領導人（AGENTS.md 第 2 節第 8 條）。

## 5. 地形
- 地面＝一張四邊形＋每格 8×8 資料貼圖，彈坑、瓦礫直接畫進貼圖，不加繪製呼叫（`battle.ts`）。新地形細節優先走這張貼圖。
- 植被、戰壕、圍牆各有自己的檔（`vegetation.ts`、`trenches.ts`、`buildings.ts`）。

## 6. 特效與逃生閥
- 每個新效果一個 `?noR<號>=1` 閥，**只加在 `src/valves.ts` 一行**，功能讀 `V.r<號>`；閥關時模擬雜湊不變、畫面逐位等於原本。`?fx=off` 一鍵關全部特效。
- 守衛：`tests/valves.mjs` 用正規表示式比對 `valves.ts` 的原始碼行；`tests/hub-budget.mjs` 比對總機行數。這兩支只有 Claude 改。

## 7. 手機預算
- 412×860 開局：繪製呼叫 ≤ 20、三角形 ≤ 80,000（含陰影那一趟）。參考 R139：開局 12 calls、約 1.5 萬三角形。
- 一種單位＝一個 InstancedMesh＝1 次呼叫（陰影另算）；單位模型建議 ≤ 400 三角形（示範半履帶車 144）。
- 零外部素材、不加 npm 套件。

## 8. 會受影響的檔案與守衛
- 美術卡主要會動：`src/render/unitArt.ts`、`buildings.ts`、`fx.ts`、`vegetation.ts`，以及新檔。`battle.ts`、`main.ts` 只加一兩行接線（行數上限在 `tools/hub-budget.json`，只准往下）。
- 比對原始碼文字的守衛：`tests/valves.mjs`、`tests/hub-budget.mjs`，另有大量 `tests/*-browser.mjs`、`*-view.mjs` 比對畫面數字；搬檔前要先改對應守衛（只由統籌做）。
- 示範：`src/render/demoUnit.ts`（R903，預設關、未接線）。
