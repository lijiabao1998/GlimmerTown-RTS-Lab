# R000 願景：同一座城的第四種時間——戰爭

**日期**：2026-10-16
**決定者**：業主（開線、二戰、GPT 無限迭代）
**整理**：Claude
**來源**：業主與 Grok、Claude 的討論（業主貼進對話的截圖），以及 Claude 讀三條既有線的結果。

## 為什麼開這條線

3D 實驗線的願景是「同一座城、三種時間」：建造、一生、考古（`GlimmerTown3D-lab/docs/D000-vision.md`）。它的原則是「3D 不是賣點，玩家做的事才是」。

戰爭是這座城的第四種時間，玩家做的事跟另外三種完全不同：**你蓋的城就是戰場，而且會被打爛。** 打完仗的傷疤（瓦礫、彈坑、燒毀的房子）以後可以寫回城市的歷史，讓考古模式讀得到。

業主原話：「核心玩法我感覺就是自己建然後給一批坦克車 榴彈砲，然後對轟，這是最簡單的玩法」。

## 核心玩法

坦克加榴彈砲對轟。三條規則讓它變成戰術：

| 單位 | 特性 | 角色 |
|---|---|---|
| 坦克 | 直射；被房子擋住時砲彈打在房子上 | 推進；轟開掩體 |
| 榴彈砲 | 射程遠、有最小射程、落點會散開；移動中不能打 | 只有友軍看得到目標時才打得準，盲射散布加倍 |
| （之後）偵察兵／觀測員 | 便宜、脆、視野遠 | 榴彈砲的眼睛 |

一回合大概是：偵察找到敵人 → 砲擊 → 敵方坦克躲到房子後面 → 你把房子轟塌 → 掩體沒了、視線通了 → 坦克推進。破壞不是特效，是戰術本身。

## 設定（Claude 預設，業主未定）

1940 年夏天的假想：英國南部小鎮，本土防衛軍守自己的鎮。這跟 3D 實驗線的英式建築一致，也是「守自己蓋的城」。入侵方用程序生成的通用灰色徽記，不畫任何真實的仇恨符號。業主想換成 1944 諾曼第、阿納姆，或完全虛構的陣營，就改這一段。

## 技術

| 項目 | 方向 |
|---|---|
| 程式 | TypeScript 7＋three.js 0.186＋Vite，輸出單一 HTML，放 GitHub Pages，手機直接開 |
| 模擬 | 純邏輯，固定 20 步／秒，只用整數；種子＋指令紀錄＝整局重播；Node 與 Chrome 算出同一個雜湊 |
| 畫面 | 固定正交斜視鏡頭（45°／30°，不旋轉，光永遠從左上來）；像素風後製沿用 3D 實驗線的畫風 A |
| 破壞 | 建築三段：完好 → 沒屋頂的空殼 → 瓦礫（門檻沿用 3D 實驗線三百年示範）；彈坑畫進地面貼圖 |
| 驗收 | Node 端守衛＋無頭 Chrome 煙霧測試＋GitHub Actions |

**Rust／WebAssembly 先不用。** 業主問過「它們說 rust 效率極高」：3D 實驗線一整座城模擬一天約 1.3 毫秒，本線 60 秒的腳本戰鬥在 Node 裡跑約 25 毫秒。瀏覽器 RTS 卡的多半是畫面，不是模擬；真的量到模擬是瓶頸，再把 `src/sim` 換成 Rust。模擬只用整數、不碰 DOM，換的時候可以照雜湊逐位元組對拍。

## 跟另外三條線的關係

- **之後匯入你自己蓋的城**：3D 實驗線的分享碼（`GlimmerTown3D-lab/src/io/labcode.ts`）可以解出地形、道路、建築與佔地；戰場從城裡切一個街區（整座城的三角形已經用掉 3D 實驗線預算的 98%，裝不下單位與砲彈）。
- **戰後寫回歷史**：先存在 RTS 自己的欄位；要讓 3D 實驗線讀得到，需要在那邊新增事件編號，那要業主核准。

## 先不做

- 多人連線（決定性模擬讓它以後做得到，現在不做）。
- 物理引擎（碎片、煙只是畫面，不影響勝負）。
